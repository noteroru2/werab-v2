## Lenovo ควรส่ง Machine Type หรือรหัสรุ่นเต็ม

ThinkPad, IdeaPad, Yoga, Legion และ LOQ มีรุ่นย่อยตาม Generation จำนวนมาก การถ่าย Machine Type/Model จากใต้เครื่องช่วยแยกสเปกได้แม่นกว่าชื่อ Series บนฝา

## ThinkPad ต้องดู Keyboard และ Port

เครื่องธุรกิจมักถูกใช้งานต่อเนื่อง ควรทดสอบ Keyboard, TrackPoint/Touchpad, USB-C, HDMI, LAN หรือ Docking interface ตามรุ่น รวมถึงตรวจรอยเงาบนคีย์และสภาพฝาบนที่เกิดจากการใช้งานจริง

## Legion และ LOQ อย่าลืม GPU

Gaming Notebook ต้องระบุ GPU เต็มพร้อม VRAM หากตรวจได้ รวมถึงขนาด RAM/SSD และ Adapter เพราะชื่อ Legion หรือ LOQ เพียงอย่างเดียวไม่บอก Configuration ที่แท้จริง

## Yoga และเครื่องพับได้ให้ตรวจบานพับกับ Touch

รุ่นที่หมุนจอได้ควรทดสอบ Touch, Rotation, Hinge และพื้นที่รอบขอบจอ หากมีอาการบานพับฝืดหรือจอเผยอไม่ควรฝืนพับหลายครั้ง

## เครื่ององค์กรควรจัดการข้อมูลก่อนส่งมอบ

หากเป็นเครื่องบริษัท ควรสำรองข้อมูล ออกจากบัญชีองค์กร และตรวจว่ามีระบบจัดการเครื่องหรือรหัส BIOS ที่ต้องปลดตามสิทธิ์ของเจ้าของก่อนขาย

## เครื่องอัปเกรดแล้วควรแยกของเดิมกับของปัจจุบัน

หากเปลี่ยน RAM หรือ SSD หลังซื้อ ควรแจ้งสเปกปัจจุบันและของเดิมที่ยังมีอยู่ เพราะบางรุ่นมีหน่วยความจำบัดกรีร่วมกับสล็อตเพิ่ม การบอกเพียงความจุรวมอาจไม่พอสำหรับการประเมินความยืดหยุ่นในการใช้งานต่อ
