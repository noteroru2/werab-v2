## รับซื้อโน๊ตบุ๊คในบึงกาฬ เช็กรุ่นก่อนเช็กราคา

โน๊ตบุ๊คชื่อคล้ายกันแต่ใช้ CPU, GPU, RAM และหน้าจอต่างกันได้มาก สิ่งแรกที่ควรทำจึงไม่ใช่ดูแค่โลโก้บนฝา แต่ต้องหาชื่อรุ่นหรือรหัส Model ให้ได้มากที่สุด

ถ้ายังไม่ทราบรุ่น ให้ถ่ายรูปใต้เครื่องและหน้า **Task Manager > Performance** ที่เห็น CPU, Memory และ GPU พร้อมรูปตัวเครื่องรอบด้าน

อ่านภาพรวมเพิ่มเติมที่ [รับซื้อโน๊ตบุ๊คมือสอง](/รับซื้อโน๊ตบุ๊ค/)

## Gaming Notebook ต้องแจ้ง GPU แยกจาก CPU
เครื่องเกมมิ่งบางรุ่นใช้ชื่อซีรีส์เดียวกันแต่มี RTX คนละรุ่น เช่น RTX 3050, 3060, 4050 หรือ 4060 การแจ้ง GPU จึงสำคัญต่อราคามาก รวมถึง Watt/TGP และหน้าจอ Refresh Rate หากทราบ

## Battery และ Adapter มีผลต่อความพร้อมใช้งาน
ควรแจ้งว่าแบตเก็บไฟได้หรือไม่ ใช้งานโดยไม่เสียบสายได้ประมาณไหน และมี Adapter เดิมหรือ Adapter เทียบ หากขั้วชาร์จหลวม สายชำรุด หรือเครื่องเตือนกำลังไฟไม่พอควรบอกด้วย

## บานพับ หน้าจอ และ Keyboard ควรถ่ายจุดตำหนิ
โน๊ตบุ๊คที่ยังเปิดได้แต่บานพับแตก กรอบจอแยก ยางบวม จอมีเส้น Dead Pixel หรือ Keyboard บางปุ่มเสียยังสามารถส่งประเมินได้ แต่ต้องประเมินเป็นสภาพมีตำหนิ ไม่ควรปิดบังจุดเสียเพื่อเทียบกับเครื่องสวย

## ผู้ขายในบึงกาฬเริ่มจากรูปและสเปกได้
ไม่ว่าจะอยู่ในอำเภอเมืองบึงกาฬ เซกา โซ่พิสัย หรือพื้นที่อื่น สามารถเริ่มขอราคาเบื้องต้นจากข้อมูลก่อนได้ หน้านี้ไม่ได้หมายความว่ามีสาขาประจำในทุกพื้นที่ หลังจากทราบช่วงราคาแล้วจึงค่อยตกลงวิธีตรวจและส่งมอบที่เหมาะสม
