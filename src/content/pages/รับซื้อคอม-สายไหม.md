## รับซื้อคอมในสายไหม เริ่มจากรูปภายใน Case และสเปก

คอมประกอบในเขตสายไหมไม่จำเป็นต้องยกทั้ง Case ไปถามราคาเบื้องต้น ถ้าสามารถเปิดเครื่องได้ ให้ส่งรูปหน้า Task Manager หรือโปรแกรมที่แสดง CPU/GPU/RAM พร้อมรูปภายใน Case ที่เห็น Mainboard, GPU และ Power Supply

ดูแนวทางหลักที่ [รับซื้อคอมมือสอง](/รับซื้อคอม/)

## ระบุให้ชัดว่าขายทั้งชุดหรือไม่
หลายเครื่องมีจอ เมาส์ Keyboard และอุปกรณ์เสริม แต่ผู้ขายต้องการขายเฉพาะ Case บางรายถอด SSD เก็บไว้เพราะมีข้อมูลส่วนตัว หรือขาย GPU แยก การแจ้งรายการที่รวมขายตั้งแต่ต้นช่วยให้ตีราคาบนฐานเดียวกัน

## คอมประกอบควรประเมินเป็นชิ้นส่วน
CPU และ GPU มักมีผลต่อมูลค่าหลัก แต่ Mainboard, RAM, SSD, PSU และชุดระบายความร้อนก็มีผลต่อความสมบูรณ์ ถ้าเป็นแบรนด์/รุ่นที่ตรวจได้ ควรถ่าย Label ให้ชัด

ดูหน้าที่เจาะคอมประกอบที่ [รับซื้อคอมประกอบ](/รับซื้อคอมประกอบ/)

## เครื่องมีอาการอย่ารีบสรุปว่าเสียที่การ์ดจอ
อาการจอดับ รีสตาร์ต หรือเปิดไม่ติดอาจมาจาก PSU, RAM, Storage, Mainboard หรือ GPU การขอราคาเบื้องต้นควรบอกอาการล่าสุดและการเปลี่ยนชิ้นส่วนที่ผ่านมา ไม่จำเป็นต้องรื้อเครื่องเพิ่มถ้าไม่มั่นใจ

## ผู้ขายในสายไหมเริ่มเช็กราคาจากข้อมูลก่อนได้
ผู้ขายในเขตสายไหมสามารถใช้หน้านี้เตรียมข้อมูลและส่งเช็กราคาได้ แต่เว็บไซต์ไม่ได้ระบุว่ามีสาขาประจำในเขตสายไหม วิธีตรวจสินค้า นัดหมาย หรือจัดส่งจะตกลงตามสถานการณ์จริงหลังจากข้อมูลและช่วงราคาตรงกัน
