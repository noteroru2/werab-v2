# GLOBAL LINK POLICY

Prefer canonical target routes.

Never link to a redirect source.

Example:

Use:

/รับซื้อแมคบุ๊ค/

Never:

/รับซื้อ-macbook/

For every global navigation target:

1. Resolve lifecycle.
2. Confirm HTTP 200.
3. Confirm route is approved for public navigation.
4. Only then render hyperlink.

Otherwise omit the link/item.
