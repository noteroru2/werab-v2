## อยู่ต่างพื้นที่ในจังหวัดเลยสามารถส่งข้อมูลมาก่อนได้

เช่นผู้ขายที่อยู่ใน:

- อำเภอเมืองเลย
- วังสะพุง
- เชียงคาน
- ด่านซ้าย
- ภูเรือ
- ปากชม
- และพื้นที่อื่นในจังหวัดเลย

สามารถเริ่มจากส่งข้อมูลผ่านช่องทางติดต่อเพื่อประเมินเบื้องต้นก่อน

จากนั้นจึงพิจารณาวิธีตรวจสินค้าและส่งมอบตามระยะทาง พื้นที่ และความเหมาะสม

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำในทุกอำเภอ

- ข้อมูล BIOS

## Battery มีผลมากกับ Notebook ที่ต้องพกพา

ควรแจ้ง:

- ใช้ Battery ได้หรือไม่
- หมดเร็วหรือไม่

- Battery Health ถ้ามี
- Battery เคยเปลี่ยนหรือไม่
- มีอาการบวมหรือไม่

- Adapter เทียบ
- ไม่มี Adapter
- Adapter มีอาการ

ไม่จำเป็นต้องซื้อใหม่เพื่อถามราคาก่อน

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในจังหวัดเลย

### อยู่ต่างอำเภอในจังหวัดเลยเช็กราคาก่อนได้ไหม?

สามารถส่ง Model สเปก รูป Battery และอาการเพื่อประเมินเบื้องต้นก่อน แล้วจึงพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

### Gaming Notebook ต้องแจ้งอะไรเพิ่ม?

ควรแจ้ง GPU และ Adapter เพิ่มจาก CPU, RAM และ SSD เพราะ Gaming Notebook Series เดียวกันอาจมีหลาย GPU Configuration

### เครื่องเก่า Battery เสื่อมยังขายได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้ง Battery และอาการอื่นตามจริง ไม่จำเป็นต้องเปลี่ยน Battery ก่อนรู้ว่าค่าใช้จ่ายคุ้มกับมูลค่าที่เพิ่มหรือไม่

### Notebook เปิดไม่ติดต้องเดินทางมาให้ตรวจก่อนหรือไม่?

สามารถเริ่มจากส่งรุ่น สเปกที่ทราบ รูป Adapter และอาการก่อน เพื่อประเมินข้อมูลเบื้องต้นโดยไม่จำเป็นต้องเดินทางเพียงเพื่อถามราคา

### ขาย Notebook โดยไม่รวม SSD ได้ไหม?

สามารถแจ้งว่าไม่รวม SSD ได้ ราคาจะประเมินจาก Configuration ที่ขายจริง และเป็นทางเลือกหนึ่งหากผู้ขายต้องการเก็บข้อมูลหรือ Drive ไว้
