## อยู่ยโสธรสามารถส่งอาการและรูปมาก่อนได้

หากเครื่องมีปัญหา ไม่จำเป็นต้องซ่อมหรือเดินทางก่อนรู้ข้อมูลเบื้องต้น

ส่ง:

- Model
- CPU
- RAM
- SSD
- GPU ถ้ามี
- Battery
- รูป
- อาการ
- Adapter

แล้วค่อยประเมินว่าควรขายตามสภาพหรือดำเนินการอย่างอื่น

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ในยโสธร

---

## เครื่องปกติกับเครื่องมีอาการต้องประเมินต่างกัน

เครื่องที่:

- เปิดได้
- เข้า Windows ได้
- ตรวจสเปกได้
- ทดสอบฟังก์ชันพื้นฐานได้

มีข้อมูลประกอบมากกว่าเครื่องที่ไม่สามารถทดสอบได้

หากเครื่องมีอาการ ควรแจ้งตามจริงแทนการพยายามทำให้ดูเหมือนปกติ

---

## จอเสียควรซ่อมก่อนขายหรือไม่

ควรเปรียบเทียบ:

1. ราคาตามสภาพ
2. ราคาจอ
3. ค่าแรง
4. ความเสี่ยงจากการซ่อม
5. มูลค่าที่คาดว่าจะเพิ่ม

จอมีเส้นหรือแตกไม่ได้หมายความว่าการเปลี่ยนจอจะคุ้มในทุกเครื่อง

---

## Battery เสื่อมควรเปลี่ยนก่อนหรือไม่

หลักการเหมือนกัน

หาก Battery เสื่อมแต่เครื่องยังใช้งานได้ ควรเช็กราคาปัจจุบันก่อน

แล้วค่อยเปรียบเทียบค่า Battery และค่าแรงกับมูลค่าที่คาดว่าจะเพิ่มขึ้น

---

## Keyboard หรือบานพับเสียต้องแจ้ง

ควรถ่ายตำหนิและแจ้งว่า:

- ปุ่มใดเสีย
- Keyboard ใช้ไม่ได้บางส่วน
- บานพับหลวม
- ฝาแตก
- Palmrest แยก
- Bottom Case แตก

ความเสียหายโครงสร้างอาจมีต้นทุนต่างจากตำหนิภายนอกทั่วไป

---

## CPU และ GPU ยังต้องแจ้งแม้เครื่องมีอาการ

เครื่องเสียไม่ได้ทำให้รุ่น Hardware หมดความสำคัญ

Gaming Notebook ที่มี GPU รุ่นสูงกับ Notebook ทั่วไปที่มีอาการเดียวกันอาจมีมูลค่าต่างกัน

ควรแจ้งสเปกเท่าที่ทราบ

---

## ไม่มี Adapter ยังประเมินได้

สามารถแจ้งว่าไม่มี Adapter ได้

ไม่ควรซื้อ Adapter ใหม่เพียงเพราะคิดว่าจะขายได้ราคาสูงขึ้นโดยยังไม่ได้เปรียบเทียบต้นทุน

---

## เคยซ่อม Mainboard ควรบอกหรือไม่

ควรแจ้งหากทราบ

รวมถึง:

- ซ่อม Board
- เปลี่ยนจอ
- เปลี่ยน Battery
- เปลี่ยน Keyboard
- ซ่อมชาร์จ
- เคยโดนน้ำ

ช่วยให้ประเมินความเสี่ยงของเครื่องได้ดีขึ้น

---

## เครื่องเปิดไม่ติดไม่ควรเปิดซ้ำโดยไม่มีเหตุผล

หากกด Power แล้วไม่ขึ้น ควรสังเกต:

- ไฟชาร์จ
- เสียง
- Fan
- ความร้อน
- อาการก่อนเสีย

แต่ถ้ามี:

- กลิ่นไหม้
- Battery บวม
- ความร้อนผิดปกติ
- ร่องรอยน้ำ

ไม่ควรทดลองเปิดซ้ำหลายครั้งเพียงเพื่อขอราคา

---

## ข้อมูลส่วนตัวไม่เกี่ยวกับการประเมินราคา Hardware

ไม่ควรส่ง:

- Password
- PIN
- OTP
- Recovery Key
- Email Password

หากต้องการเก็บ SSD สามารถแจ้งว่าไม่รวม Storage ได้

ราคาจะประเมินจากสิ่งที่ขายจริง

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในยโสธร

### จอแตกต้องซ่อมก่อนขายหรือไม่?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพก่อนแล้วเปรียบเทียบค่าอะไหล่และค่าแรงกับมูลค่าที่คาดว่าจะเพิ่ม

### Battery เสื่อมยังขายได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้ง Health หรืออาการใช้งานตามจริง

### เครื่องเปิดไม่ติดต้องซ่อมก่อนเช็กราคาไหม?

ไม่จำเป็น สามารถเริ่มจาก Model สเปก รูป Adapter และอาการเพื่อประเมินเบื้องต้นก่อน

### เคยซ่อม Mainboard ต้องแจ้งหรือไม่?

ควรแจ้งหากทราบ เพราะเป็นข้อมูลประกอบสภาพและความเสี่ยงของเครื่อง

### ไม่มี Adapter ยังประเมินได้ไหม?

ได้ ควรแจ้งว่าไม่มี Adapter และไม่จำเป็นต้องซื้อใหม่ก่อนเปรียบเทียบความคุ้มค่า
