## เลือกประเภทสินค้าที่ต้องการขาย

### โน๊ตบุ๊คและ Gaming Notebook

ควรเตรียม:

**รุ่น + CPU + RAM + SSD + GPU + Battery + Adapter + รูป**

เหมาะกับ Notebook, Laptop, Gaming Notebook และเครื่องที่มีตำหนิบางประเภท

---

### คอมพิวเตอร์ Desktop และ Gaming PC

ควรเตรียม:

**CPU + GPU + RAM + SSD + Mainboard + PSU + รูปเครื่อง**

คอมประกอบควรประเมินจากชิ้นส่วนจริง ไม่ควรดูเพียงราคาที่เคยประกอบมา

---

### MacBook

ควรเตรียม:

**รุ่น + Chip หรือ Processor + RAM + SSD + Battery + รูป + อุปกรณ์**

ควรแยก Intel และ Apple Silicon ให้ชัด

---

### iPhone

ควรเตรียม:

**รุ่น + ความจุ + Battery Health + รูป + สภาพ + อาการ**

ควรตรวจหน้าจอ Face ID หรือ Touch ID กล้องและประวัติซ่อม

---

### iPad

ควรเตรียม:

**รุ่น + Generation + ความจุ + Wi-Fi/Cellular + รูป + สภาพ**

หากมี Apple Pencil หรือ Keyboard ควรแจ้งแยก

---

### กล้องและเลนส์

ควรเตรียม:

**รุ่น Body + รุ่น Lens + รูป + สภาพ + Shutter ถ้าทราบ + อุปกรณ์**

Body และ Lens ควรแยกประเมินก่อนรวมเป็นชุด

---

### ลำโพง

ควรเตรียม:

**Brand + Model + รูป + Battery + การเชื่อมต่อ + สภาพ + อุปกรณ์**

ควรแจ้งหากเสียงแตก Battery เสื่อม หรือมีอาการเชื่อมต่อผิดปกติ

---

### ซากคอมพิวเตอร์และอุปกรณ์เสีย

ควรเตรียม:

**ประเภทสินค้า + รุ่นหรือสเปกที่ทราบ + อาการ + รูป + ชิ้นส่วนที่ยังอยู่**

เครื่องเสียหนักควรประเมินจากมูลค่าชิ้นส่วนที่เหลือ ไม่ควรใช้ราคาเครื่องปกติเป็นฐานตรง ๆ

---

### Server และอุปกรณ์องค์กร

ควรเตรียม:

**Brand + Model + CPU + RAM + Storage + Controller + จำนวน + สภาพ**

หากมีหลายเครื่องควรทำเป็นรายการหรือตาราง

---

## ทำไมต้องแยกข้อมูลตามประเภทสินค้า

สินค้าไอทีแต่ละประเภทมีจุดที่ส่งผลต่อมูลค่าแตกต่างกัน

ตัวอย่าง:

- Notebook เน้น CPU, GPU, Battery และหน้าจอ
- Gaming PC เน้น GPU, CPU, PSU และชิ้นส่วนภายใน
- iPhone เน้นรุ่น ความจุ Battery และฟังก์ชันสำคัญ
- iPad เน้น Generation ความจุ หน้าจอและอุปกรณ์
- MacBook เน้น Chip, RAM, SSD, Battery และบัญชี
- กล้องเน้น Body, Lens, Sensor และ Shutter

การส่งข้อมูลให้ตรงประเภทช่วยลดการถามซ้ำและช่วยให้ประเมินได้แม่นขึ้น

---

## สินค้ามีตำหนิยังเช็กราคาได้ไหม

หลายกรณีสามารถส่งมาประเมินตามสภาพได้

ตัวอย่าง:

- จอแตก
- Battery เสื่อม
- ไม่มี Adapter
- มีรอย
- เคยซ่อม
- เปิดไม่ติด
- บางฟังก์ชันเสีย

ควรแจ้งตำหนิตามจริงตั้งแต่ต้น

การประเมินเครื่องมีตำหนิต้องเผื่อต้นทุนและความเสี่ยงต่างจากเครื่องปกติ

---

## ควรซ่อมก่อนขายหรือไม่

ไม่จำเป็นต้องซ่อมทุกกรณี

ก่อนซ่อมควรเปรียบเทียบ:

1. ราคาตามสภาพปัจจุบัน
2. ค่าใช้จ่ายในการซ่อม
3. ความเสี่ยงของการซ่อม
4. มูลค่าที่คาดว่าจะเพิ่ม
5. ระยะเวลาที่ต้องใช้

บางกรณีขายตามสภาพอาจเหมาะกว่า ขณะที่บางเครื่องอาจคุ้มกับการซ่อม

ควรเช็กราคาก่อนตัดสินใจ

---

## ไม่ทราบรุ่นหรือสเปกทำอย่างไร

สามารถเริ่มจากรูปได้

ควรถ่าย:

- ตัวสินค้า
- ป้ายรุ่น
- Sticker
- หน้าจอข้อมูลระบบ
- Serial หรือข้อมูลที่จำเป็นโดยปิดบังส่วนที่ไม่ต้องการเปิดเผย
- จุดตำหนิ

สำหรับคอมและ Notebook สามารถใช้ Task Manager หรือ System Information ช่วยดูสเปก

สำหรับอุปกรณ์ Apple สามารถดูข้อมูลจาก Settings หรือ About This Mac

---

## ต้องส่งข้อมูลส่วนตัวเพื่อเช็กราคาไหม

ไม่ควรส่งข้อมูลส่วนตัวที่ไม่จำเป็น

ไม่ต้องส่ง:

- Password
- Apple ID Password
- OTP
- Recovery Key
- รหัสผ่านธนาคาร
- ข้อมูลบัญชีส่วนตัว

หากรูปหน้าจอมีข้อมูลส่วนตัว สามารถปิดบังก่อนส่งได้

การเช็กราคาเบื้องต้นควรใช้ข้อมูลสินค้าเป็นหลัก

---

## อยู่ต่างจังหวัดเริ่มอย่างไร

สามารถเริ่มด้วยการส่งข้อมูลและรูปออนไลน์ก่อนได้

ไม่จำเป็นต้องเดินทางพร้อมสินค้าทันทีเพียงเพื่อขอราคาประเมิน

หลังจากทราบรายละเอียดเบื้องต้นแล้วจึงค่อยตกลงวิธีส่งมอบหรือนัดหมายตามประเภทสินค้า พื้นที่ และความเหมาะสม

การมีหน้าบริการระดับประเทศไม่ได้หมายความว่ามีสาขาอยู่ในทุกจังหวัด

## คำถามที่พบบ่อย

### รับซื้อสินค้าไอทีประเภทไหนบ้าง?

สามารถส่ง Notebook คอม MacBook iPhone iPad กล้อง ลำโพง Server และอุปกรณ์ไอทีหลายประเภทมาประเมินได้ โดยต้องดูรุ่น สเปก สภาพและตลาดของสินค้าแต่ละประเภท

### สินค้ามีตำหนิหรือเสียยังเช็กราคาได้ไหม?

หลายกรณีสามารถประเมินตามสภาพได้ ควรแจ้งอาการและตำหนิอย่างชัดเจน เพราะเครื่องเสียหรือเครื่องมีปัญหาจะมีความเสี่ยงและต้นทุนต่างจากเครื่องปกติ

### ต้องมีอุปกรณ์ครบหรือมีกล่องไหม?

ไม่จำเป็นต้องครบทุกกรณี ควรแจ้งว่ามี Adapter สาย Charger Box หรืออุปกรณ์ใดอยู่บ้าง เพื่อประเมินจากชุดที่ขายจริง

### ไม่รู้รุ่นหรือสเปกสามารถสอบถามได้ไหม?

สามารถเริ่มจากส่งรูปสินค้า ป้ายรุ่น หรือหน้าจอข้อมูลระบบ เพื่อช่วยระบุข้อมูลเบื้องต้นก่อนประเมิน

### อยู่ต่างจังหวัดสามารถเริ่มเช็กราคาได้ไหม?

สามารถเริ่มส่งข้อมูลและรูปเพื่อประเมินเบื้องต้นก่อนได้ จากนั้นจึงค่อยพิจารณาวิธีส่งมอบหรือนัดหมายตามความเหมาะสม
