## อยู่ในนครพนมสามารถส่งข้อมูลเช็กราคาก่อนได้

ไม่จำเป็นต้องเดินทางพร้อมเครื่องเพียงเพื่อสอบถามราคาเบื้องต้น

สามารถเริ่มจาก:

- รูปเครื่อง
- Model
- สเปก
- Battery
- อาการ
- Adapter
- จุดตำหนิ

แล้วจึงค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ของจังหวัดนครพนม

---

## Notebook รุ่นเก่าต้องรู้ Generation

คำว่า Core i5 หรือ Core i7 อย่างเดียวอาจยังไม่พอ

ตัวอย่างเช่น:

- Core i5-8250U
- Core i5-1135G7
- Core i5-12450H
- Ryzen 5 5500U
- Ryzen 5 7530U

เป็น CPU คนละ Generation และ Platform

ควรแจ้งรหัสเต็มเท่าที่ตรวจได้

---

## เครื่องธุรกิจและ Notebook สำนักงานควรดูอะไร

Notebook กลุ่ม Business มักต้องพิจารณา:

- Model
- CPU
- RAM
- SSD
- หน้าจอ
- Keyboard
- Battery
- Port
- Adapter
- สภาพตัวเครื่อง

หากเป็นเครื่องจากบริษัทหลายเครื่อง ควรแยก Configuration ให้ถูกต้อง ไม่ควรใช้ข้อมูลเครื่องเดียวแทนทั้งหมด

---

## Gaming Notebook ต้องแจ้ง GPU

หากเป็น Gaming Notebook ควรระบุ:

- CPU
- GPU
- RAM
- SSD
- Adapter
- หน้าจอถ้าทราบ

เช่น:

**RTX 3060 Laptop GPU**

หรือ

**RTX 4060 Laptop GPU**

ชื่อ Gaming Series อย่างเดียวอาจมีหลาย Configuration

---

## RAM และ SSD ควรแจ้งของที่ติดตั้งอยู่จริง

หากเคยอัปเกรดควรใช้ข้อมูลปัจจุบัน

ตัวอย่าง:

**RAM 16GB / SSD 1TB**

ถ้าต้องการเก็บ SSD ไว้ ควรแจ้งตั้งแต่ก่อนประเมินว่า:

**ไม่รวม SSD**

เพื่อให้ราคาพิจารณาจากของที่ขายจริง

---

## Battery เสื่อมยังประเมินได้ไหม

ได้

ควรแจ้งว่า:

- Battery ใช้งานได้
- หมดเร็ว
- ไม่เก็บไฟ
- ต้องเสียบ Adapter
- Health ต่ำ
- เคยเปลี่ยน
- Battery บวม

หาก Battery บวมควรหลีกเลี่ยงการกดหรือใช้งานเครื่องหนักโดยไม่จำเป็น

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในนครพนม

### Notebook รุ่นเก่ายังเช็กราคาได้ไหม?

ได้ ควรแจ้ง Model, CPU, RAM, SSD, Battery และสภาพเพื่อประเมินจาก Configuration จริงก่อนตัดสินใจซ่อมหรือขาย

### Gaming Notebook ต้องแจ้ง GPU หรือไม่?

ควรแจ้งรุ่น GPU เต็ม เพราะเครื่องชื่อ Series เดียวกันอาจมีหลาย GPU Configuration

### Battery เสื่อมต้องเปลี่ยนก่อนขายไหม?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพแล้วเปรียบเทียบค่าเปลี่ยน Battery กับมูลค่าที่เพิ่มขึ้น

### เครื่องเปิดไม่ติดสามารถประเมินก่อนได้หรือไม่?

สามารถส่ง Model สเปกที่ทราบ รูป Adapter และอาการก่อน เพื่อประเมินความเป็นไปได้เบื้องต้น

### ขาย Notebook โดยไม่รวม SSD ได้ไหม?

สามารถแจ้งว่าไม่รวม SSD ได้ โดยราคาต้องอิง Configuration ที่ขายจริง
