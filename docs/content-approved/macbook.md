# รับซื้อ MacBook มือสอง เช็กรุ่น ชิป แบตเตอรี่และสภาพก่อนขาย
MacBook แต่ละ Generation มีความต้องการมือสองต่างกัน


---


## ขั้นตอนเช็กราคา MacBook ก่อนขาย


### 1. ส่งรุ่น


หากไม่ทราบ ให้ส่งหน้า About This Mac


### 2. ส่ง Configuration


อย่างน้อย:


**Chip + RAM + SSD**


### 3. ส่งข้อมูล Battery


ถ้ามี:


**Cycle Count + Condition**


### 4. ส่งรูป


ถ่าย:


- ฝาบน
- หน้าจอ
- Keyboard
- Trackpad
- ใต้เครื่อง
- มุมทุกด้าน
- ตำหนิ


### 5. แจ้งอุปกรณ์


เช่น Adapter, Cable และ Box


### 6. แจ้งประวัติและอาการ


ระบุว่าเคยซ่อมหรือมีปัญหาอะไร


### 7. ประเมินเบื้องต้น


ใช้ข้อมูลรุ่น Configuration และสภาพร่วมกัน


### 8. ตัดสินใจ


ผู้ขายสามารถพิจารณาก่อนว่าจะขายหรือเก็บเครื่องไว้


### 9. เตรียมบัญชีและข้อมูล


เมื่อพร้อมขายจึง Backup, Sign out และล้างข้อมูลก่อนส่งมอบ


### 10. ตรวจเครื่องจริงและซื้อขาย


ตรวจข้อมูลและสภาพให้ตรงกับที่ใช้ประเมินก่อนดำเนินการซื้อขาย


---


## อยู่ต่างจังหวัดสามารถเริ่มเช็กราคาได้อย่างไร


ไม่จำเป็นต้องเดินทางพร้อม MacBook เพียงเพื่อถามราคาเบื้องต้น


เริ่มจากส่ง:


**รุ่น + Chip + RAM + SSD + Battery + รูป + สภาพ + อุปกรณ์**


จากนั้นจึงพิจารณาวิธีส่งมอบหรือนัดหมายตามพื้นที่และความเหมาะสม


หน้า `/รับซื้อแมคบุ๊ค/` เป็นข้อมูลบริการภาพรวม ไม่ได้ใช้เพื่ออ้างว่ามีสาขาในทุกจังหวัด

faqItems:
  - question: "รับซื้อ MacBook Air และ MacBook Pro มือสองไหม?"
    answer: "สามารถส่ง MacBook Air และ MacBook Pro หลายรุ่นมาประเมินได้ ทั้งรุ่น Intel และ Apple Silicon โดยควรแจ้งรุ่น ชิป RAM SSD สภาพแบตเตอรี่ ตัวเครื่อง และอุปกรณ์"


  - question: "MacBook แบตเสื่อมหรือ Cycle สูงขายได้ไหม?"
    answer: "สามารถส่งมาประเมินตามสภาพได้ ควรแจ้ง Cycle Count, Battery Condition และอาการใช้งานจริง เพราะจำนวน Cycle เพียงอย่างเดียวไม่ได้บอกสภาพแบตเตอรี่ทั้งหมด"


  - question: "MacBook ไม่มีกล่องหรือ Adapter ขายได้ไหม?"
    answer: "สามารถส่งมาประเมินได้ โดยควรแจ้งอุปกรณ์ที่มีอยู่จริง ราคาอาจพิจารณาความครบของชุดและต้นทุน Adapter ของแต่ละรุ่นร่วมด้วย"


  - question: "MacBook เคยซ่อมหรือเปลี่ยนจอยังขายได้ไหม?"
    answer: "สามารถส่งมาประเมินได้ ควรแจ้งประวัติการซ่อมหากทราบ เช่น เปลี่ยนหน้าจอ Battery Keyboard หรือซ่อม Logic Board เพื่อช่วยตรวจสภาพและความเสี่ยงได้ตรงขึ้น"


  - question: "ต้องล้าง MacBook ก่อนส่งรูปเช็กราคาหรือไม่?"
    answer: "ไม่จำเป็นต้องล้างข้อมูลเพื่อเช็กราคา ควร Backup และจัดการบัญชี Apple รวมถึง Find My เมื่อพร้อมส่งมอบเครื่องจริง"
