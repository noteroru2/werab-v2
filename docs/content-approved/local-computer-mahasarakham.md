## อยู่มหาสารคามสามารถส่งสเปกคอมมาเช็กราคาก่อนได้

ไม่จำเป็นต้องยกคอมทั้งเครื่องไปเพียงเพื่อสอบถามราคาเบื้องต้น

สามารถเริ่มจากส่ง:

- CPU
- GPU
- RAM
- SSD หรือ HDD
- Mainboard
- PSU
- Case
- รูปเครื่อง
- อาการ
- อุปกรณ์ที่รวมขาย

หากยังตรวจสเปกไม่ครบ สามารถเริ่มจากข้อมูลที่มีแล้วค่อยตรวจเพิ่มเติม

หลังทราบข้อมูลเบื้องต้นจึงค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

หน้า Local นี้ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ของจังหวัดมหาสารคาม

## CPU ต้องแจ้งรุ่นเต็ม

คำว่า:

**Core i5**

หรือ

**Ryzen 5**

ยังไม่เพียงพอสำหรับประเมินคอม

ควรแจ้งรหัสเต็ม เช่น:

**Intel Core i5-12400F**

**Intel Core i7-12700**

**AMD Ryzen 5 5600**

**AMD Ryzen 7 5700X**

CPU คนละ Generation อาจใช้ Platform คนละรุ่นและมีมูลค่าต่างกัน

---

## การ์ดจอควรระบุรุ่นและความจุให้ถูก

สำหรับ Gaming PC หรือเครื่องทำงานกราฟิก ควรแจ้ง GPU เช่น:

**GeForce RTX 3060 12GB**

**GeForce RTX 4060 8GB**

หรือรุ่นอื่นตามเครื่องจริง

ถ้าทราบ Brand หรือรุ่นย่อยสามารถแจ้งเพิ่มได้

ไม่ควรประเมินจากคำว่า:

**RTX**

อย่างเดียว

เพราะแต่ละรุ่นมีประสิทธิภาพและตลาดต่างกัน

---

## RAM ควรแจ้งทั้งความจุและจำนวนแถวถ้าทราบ

ตัวอย่าง:

**16GB (8GB × 2)**

หรือ

**32GB (16GB × 2)**

หากทราบว่าเป็น DDR4 หรือ DDR5 สามารถแจ้งประกอบได้

เครื่องที่มี RAM ความจุเท่ากันอาจใช้ Platform ต่างกัน จึงควรพิจารณาร่วมกับ CPU และ Mainboard

---

## SSD และ HDD ต้องแจ้งตามของที่รวมขายจริง

ควรแจ้ง:

- SSD NVMe
- SSD SATA
- HDD
- ความจุ
- จำนวน Drive

ตัวอย่าง:

**NVMe SSD 512GB + HDD 1TB**

หากต้องการเก็บ Storage ที่มีข้อมูลส่วนตัวไว้ ควรแจ้งว่า:

**ไม่รวม SSD**

หรือ

**ไม่รวม HDD**

ตั้งแต่ก่อนประเมิน

---

## Mainboard ช่วยบอก Platform และความสามารถในการอัปเกรด

หากตรวจได้ ควรแจ้งรุ่น Mainboard เช่น:

**B550**

**B660**

**B760**

**A520**

หรือชื่อรุ่นเต็ม

Mainboard มีผลต่อ:

- CPU ที่รองรับ
- RAM
- Slot
- Storage
- Port
- การอัปเกรด

จึงไม่ควรประเมินคอมจาก CPU และ GPU เพียงสองอย่าง

---

## PSU ควรระบุยี่ห้อ รุ่น และกำลังไฟถ้าทราบ

สำหรับ Gaming PC โดยเฉพาะเครื่องที่มีการ์ดจอแยก ควรแจ้ง PSU

ตัวอย่าง:

**650W 80+**

แต่หากทราบเฉพาะกำลังไฟก็สามารถส่งข้อมูลเท่าที่มีได้

ไม่ควรเปิด PSU หรือแกะชิ้นส่วนภายในเพียงเพื่อเช็กข้อมูลก่อนขาย

---

## Case และสภาพภายนอกมีผลต่อความพร้อมใช้งาน

ควรถ่าย:

- ด้านหน้า
- ด้านข้าง
- ด้านในที่มองเห็นได้
- ด้านหลัง
- Port
- Tempered Glass ถ้ามี

ควรแจ้งหาก:

- ฝาแตก
- กระจกแตก
- มีสนิม
- Port หน้าเสีย
- Fan ไม่หมุน
- RGB มีปัญหา
- Case บุบ

ไม่จำเป็นต้องเปลี่ยน Case ก่อนเช็กราคา

## เครื่องเปิดติดแต่มีอาการควรแจ้งตามจริง

ตัวอย่าง:

- เปิดแล้วดับ
- Restart
- จอฟ้า
- ค้าง
- การ์ดจอไม่ขึ้น
- ภาพแตก
- เล่นเกมแล้วดับ
- Fan เสียงดัง
- ความร้อนผิดปกติ

ควรแจ้งว่าอาการเกิดขึ้นเมื่อใดและเกิดบ่อยแค่ไหนเท่าที่ทราบ

ไม่ควรวินิจฉัยว่า Mainboard, PSU หรือ GPU เสียโดยยังไม่ได้ตรวจ

## คำถามที่พบบ่อยเกี่ยวกับการขายคอมในมหาสารคาม

### Gaming PC ต้องแจ้งสเปกอะไรบ้าง?

ควรแจ้ง CPU, GPU, RAM, SSD, Mainboard และ PSU รวมถึงรูปและอาการถ้ามี เพราะชื่อ Gaming PC อย่างเดียวไม่สามารถบอก Configuration ได้ครบ

### ต้องรวมจอขายกับเครื่องหรือไม่?

ไม่จำเป็น สามารถแจ้งได้ว่าขายเฉพาะตัวเครื่องหรือรวม Monitor และอุปกรณ์ใดบ้าง

### ต้องล้างข้อมูลใน SSD ก่อนถามราคาไหม?

เพื่อถามราคาไม่จำเป็นต้องส่งข้อมูลส่วนตัว หากต้องการเก็บ SSD สามารถแจ้งว่าไม่รวม Storage แล้วประเมินจาก Hardware ที่ขายจริง

### คอมเปิดไม่ติดยังประเมินได้ไหม?

ได้ สามารถส่งสเปกที่ทราบ รูปและอาการก่อนเสียเพื่อประเมินเบื้องต้น โดยไม่ควรเปิดซ้ำหลายครั้งหากมีกลิ่นไหม้หรือความร้อนผิดปกติ

### มีคอมสำนักงานหลายเครื่องส่งรายการมาได้ไหม?

ได้ ควรแบ่งตาม CPU, RAM, SSD, GPU จำนวนและสภาพ เพื่อไม่ให้ใช้ Configuration ของเครื่องเดียวแทนทั้งล็อต
