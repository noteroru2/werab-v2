## Battery ควรแจ้งอย่างไร

สำหรับรุ่นที่สามารถตรวจ Battery Health ได้ ควรส่งข้อมูลนั้นประกอบ

หากไม่มีเปอร์เซ็นต์ Health ให้แจ้งอาการจริง เช่น

- ใช้งานได้ปกติ
- หมดเร็ว
- ดับเมื่อ Battery เหลือน้อย
- ชาร์จช้า
- Battery บวม
- เคยเปลี่ยน Battery

หาก Battery บวมควรหลีกเลี่ยงการกดเครื่องหรือใช้งานหนักโดยไม่จำเป็น

## เครื่องเคยเปลี่ยนจอหรือ Battery ยังขายได้ไหม

สามารถส่งข้อมูลมาประเมินตามสภาพได้

ควรแจ้งหากทราบว่าเคย:

- เปลี่ยนจอ
- เปลี่ยน Battery
- เปลี่ยนฝาหลัง
- เปลี่ยนกล้อง
- ซ่อม Board
- ซ่อมระบบชาร์จ
- โดนน้ำ
- ตกกระแทกหนัก

ประวัติซ่อมไม่ได้แปลว่าเครื่องไม่มีมูลค่า แต่มีผลต่อการประเมินความเสี่ยงและสภาพ

## เครื่องติดล็อกบัญชีต้องแจ้งก่อน

ก่อนส่งมอบจริง เจ้าของควรตรวจเรื่องบัญชีของตนเอง เช่น Apple ID หรือบัญชีผู้ผลิตที่ผูกกับเครื่อง

เพื่อขอราคาประเมินไม่ควรส่ง:

- Password
- PIN
- OTP
- Recovery Code
- Email Password
- รหัสยืนยันบัญชี

การประเมิน Hardware ไม่จำเป็นต้องได้รับรหัสลับเหล่านี้

## IMEI หรือ Serial ควรส่งเมื่อไร

สำหรับการสอบถามราคาเบื้องต้น สามารถเริ่มจากรุ่น ความจุ และรูปก่อน

หากจำเป็นต้องใช้ IMEI หรือ Serial ในขั้นตอนตรวจสอบภายหลัง ควรส่งผ่านช่องทางที่เหมาะสม และไม่ควรนำข้อมูลระบุตัวเครื่องไปโพสต์สาธารณะโดยไม่จำเป็น

---

## มีกล่องหรือไม่มีอุปกรณ์มีผลไหม

ควรแจ้งสิ่งที่รวมขายจริง เช่น

- กล่อง
- สายชาร์จ
- Adapter
- เคส
- ใบเสร็จ
- อุปกรณ์อื่น

ไม่มีอุปกรณ์บางอย่างยังสามารถส่งมาเช็กราคาได้

ไม่จำเป็นต้องซื้อกล่องหรืออุปกรณ์ใหม่เพียงเพื่อเพิ่มความครบก่อนรู้ว่าคุ้มค่าหรือไม่

- Model

## ผู้ขายในภาคอีสานควรเริ่มจากข้อมูลก่อนการเดินทาง

ไม่ว่าจะอยู่จังหวัดใดในภาคอีสาน ขั้นตอนแรกสามารถเริ่มจากส่งข้อมูลเครื่องเพื่อเช็กราคาเบื้องต้น

หลังจากทราบข้อมูลและความเป็นไปได้แล้ว จึงค่อยพิจารณาวิธีตรวจสินค้าและส่งมอบตามพื้นที่จริง

หน้านี้ไม่ได้หมายความว่า:

- มีสาขาในทุกจังหวัด
- มีพนักงานประจำทุกพื้นที่
- รับประกันว่าจะเดินทางไปรับทุกกรณี

## คำถามที่พบบ่อยเกี่ยวกับการขายโทรศัพท์มือถือมือสองในภาคอีสาน

### อยู่ต่างจังหวัดในภาคอีสานสามารถส่งรูปเช็กราคาก่อนได้ไหม?

สามารถเริ่มจากส่งรุ่น ความจุ รูป Battery และสภาพเพื่อประเมินเบื้องต้นก่อน แล้วจึงค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

### Android และ iPhone ใช้ข้อมูลประเมินเหมือนกันหรือไม่?

มีข้อมูลพื้นฐานร่วมกัน เช่น รุ่น ความจุ สภาพหน้าจอ Battery และประวัติซ่อม แต่รายละเอียดเฉพาะรุ่นหรือระบบอาจแตกต่างกัน จึงควรแจ้งรุ่นเต็มของเครื่อง

### เครื่องเปลี่ยนจอหรือ Battery มาแล้วขายได้ไหม?

สามารถส่งข้อมูลมาประเมินตามสภาพได้ ควรแจ้งประวัติที่ทราบและอาการปัจจุบันตามจริง

### เครื่องเปิดไม่ติดยังเช็กราคาได้ไหม?

สามารถเริ่มจากรุ่น ความจุ รูป อาการ ประวัติตก โดนน้ำหรือซ่อมได้ แต่เครื่องที่ไม่สามารถทดสอบได้จะมีความไม่แน่นอนมากกว่าเครื่องใช้งานปกติ

### ต้องส่ง Password หรือรหัสปลดล็อกเพื่อถามราคาหรือไม่?

ไม่ต้องส่ง Password, PIN, OTP หรือ Recovery Code เพื่อขอราคาประเมินเบื้องต้น
