## CPU มีผลต่อราคาอย่างไร

CPU เป็นหนึ่งในข้อมูลสำคัญของ Notebook

ตัวอย่างกลุ่มที่พบได้ เช่น

### Intel

- Core i3
- Core i5
- Core i7
- Core i9
- Core Ultra
- รุ่นประหยัดพลังงานหรือรุ่นประสิทธิภาพสูง

### AMD

- Ryzen 3
- Ryzen 5
- Ryzen 7
- Ryzen 9
- Ryzen AI และรุ่นอื่น

สิ่งสำคัญไม่ใช่ดูเพียงคำว่า i7 หรือ Ryzen 7

ต้องดู **Generation และรหัสรุ่นเต็ม** ด้วย

ตัวอย่างเช่น Core i7 ต่าง Generation อาจมีอายุ ประสิทธิภาพ และตลาดมือสองแตกต่างกันมาก

ดังนั้นควรส่งรหัส CPU เต็ม เช่น

`i5-12450H`

หรือ

`Ryzen 7 7735HS`

แทนการแจ้งเพียงว่า “i5” หรือ “Ryzen 7”

## RAM และ SSD มีผลต่อมูลค่าเครื่อง

Notebook รุ่นเดียวกันอาจติดตั้ง RAM และ Storage ไม่เท่ากัน

ข้อมูลที่ควรแจ้ง เช่น

- RAM 8GB / 16GB / 32GB
- DDR4 / DDR5
- SSD 256GB / 512GB / 1TB
- NVMe หรือ SATA
- มี HDD เพิ่มหรือไม่

หากมีการอัปเกรดภายหลังควรแจ้งด้วย

อย่างไรก็ตาม ราคาที่เพิ่มขึ้นจากการอัปเกรดไม่ได้จำเป็นต้องเท่ากับราคาที่เคยซื้อ RAM หรือ SSD มา

ต้องพิจารณาร่วมกับรุ่นเครื่องและตลาดของเครื่องนั้น

## Gaming Notebook ต้องดูการ์ดจอ

สำหรับ Gaming Notebook การ์ดจอมักเป็นหนึ่งในส่วนที่มีผลต่อราคามาก

ควรแจ้ง GPU เต็ม เช่น

- GTX 1650
- GTX 1660 Ti
- RTX 3050
- RTX 3060
- RTX 4050
- RTX 4060
- RTX 4070
- หรือรุ่นอื่น

ไม่ควรแจ้งเพียงว่า “การ์ดจอ NVIDIA”

เพราะมูลค่าและประสิทธิภาพของแต่ละรุ่นต่างกันมาก

Gaming Notebook ที่ใช้ CPU ใกล้เคียงกัน แต่ GPU ต่างกัน สามารถมีราคามือสองแตกต่างกันได้อย่างชัดเจน

- จอติดปกติหรือไม่

## แบตเตอรี่เสื่อมยังขายได้ไหม

ได้

แบตเตอรี่เป็นชิ้นส่วนที่เสื่อมตามการใช้งาน และ Notebook หลายเครื่องยังสามารถประเมินได้แม้ Battery ไม่สมบูรณ์

ควรแจ้งอาการตามจริง เช่น

- แบตอยู่ได้กี่ชั่วโมงโดยประมาณ
- ต้องเสียบ Adapter ตลอดหรือไม่
- Battery ไม่ชาร์จ
- เปอร์เซ็นต์แบตลดเร็ว
- เครื่องดับเมื่อถอดสาย
- Battery บวม

หากระบบแสดง Battery Health หรือ Cycle Count สามารถส่งข้อมูลประกอบได้

ไม่จำเป็นต้องเปลี่ยน Battery ก่อนสอบถามราคา

## ไม่มี Adapter หรือกล่องยังขายได้ไหม

สามารถส่งมาประเมินได้

ควรแจ้งว่ามีอะไรอยู่กับเครื่องบ้าง เช่น

- Adapter
- สายไฟ
- กล่อง
- คู่มือ
- กระเป๋า
- ใบเสร็จ
- อุปกรณ์เสริม

Adapter ของบางรุ่นมีราคาทดแทนไม่สูงมาก แต่บาง Gaming Notebook หรือ Workstation ใช้ Adapter กำลังสูงและมีต้นทุนมากกว่า

ดังนั้นผลต่อราคาจะแตกต่างกันตามรุ่น

ก่อนซื้อ Adapter ใหม่เพื่อเตรียมขาย ควรเปรียบเทียบต้นทุนก่อน

ไม่ควรถอดทิ้งชิ้นส่วนก่อนตรวจสอบหากยังไม่ทราบว่าปัญหาอยู่จุดไหน

## วิธีดูสเปกโน๊ตบุ๊คใน Windows

หากเครื่องยังเปิด Windows ได้ สามารถดูข้อมูลเบื้องต้นได้หลายวิธี

### Task Manager

กด:

`Ctrl + Shift + Esc`

เลือก Performance

สามารถดูข้อมูลเช่น

- CPU
- RAM
- GPU
- Disk

### System Information

ค้นหา:

`System Information`

สามารถดูข้อมูลเครื่องและ Processor ได้เพิ่มเติม

### Settings

เข้า:

Settings → System → About

เพื่อดู Processor และ Installed RAM

ถ้าไม่แน่ใจ สามารถถ่ายรูปหน้าข้อมูลเหล่านี้ส่งมาประกอบการประเมินได้

## Gaming Notebook ก่อนขายควรทดสอบอะไร

สำหรับเครื่องเกมมิ่ง แนะนำทดสอบเพิ่มจาก Notebook ทั่วไป

### GPU

ตรวจว่า Windows และ Driver มองเห็นการ์ดจอปกติ

### ความร้อน

สังเกตว่าเครื่องร้อนผิดปกติหรือดับเมื่อใช้งานหนักหรือไม่

### พัดลม

ฟังเสียงพัดลมว่ามีเสียงดังผิดปกติหรือไม่

### Keyboard

ตรวจปุ่ม โดยเฉพาะปุ่มที่ใช้เล่นเกมบ่อย

### จอ

ดู Refresh Rate และอาการภาพผิดปกติ

### Adapter

Gaming Notebook หลายรุ่นต้องใช้ Adapter กำลังสูง หาก Adapter ไม่ตรงรุ่นควรแจ้ง

ควรถ่ายรูปให้เห็น:

- ฝาหลังจอ
- Keyboard
- Palm Rest
- Touchpad
- ขอบเครื่อง
- พอร์ต
- ใต้เครื่อง
- บานพับ

จุดที่ควรแจ้งเป็นพิเศษ เช่น

- ฝาแตก
- บานพับแตก
- ตัวเครื่องบุบ
- รอยตก
- พอร์ตหลวม
- Keyboard หลุด
- Touchpad มีปัญหา
- น็อตหาย
- เคยแกะเครื่อง

การส่งรูปตำหนิชัดเจนช่วยลดความคลาดเคลื่อนระหว่างราคาประเมินเบื้องต้นกับสภาพจริง

## ควรล้างข้อมูลก่อนขายเมื่อไร

ไม่ควรรีบล้างข้อมูลก่อนที่คุณจะ Backup สิ่งสำคัญเรียบร้อยแล้ว

1. Backup เอกสาร
2. Backup รูป

หากยังอยู่ในขั้นตอนเช็กราคา ไม่จำเป็นต้องล้างข้อมูลเพื่อถามราคาเพียงอย่างเดียว

## โน๊ตบุ๊คบริษัทหรือมีหลายเครื่อง

ถ้ามี Notebook หลายเครื่อง การส่งข้อมูลเป็นตารางจะช่วยให้ตรวจง่ายขึ้น

ตัวอย่าง:

| รุ่น | CPU | RAM | SSD | GPU | จำนวน | สภาพ |
|---|---|---|---|---|---|---|

ถ้าเครื่องมีสเปกเหมือนกันหลายเครื่อง สามารถรวมเป็นกลุ่มได้

ควรถ่ายรูปสภาพตัวอย่างของแต่ละกลุ่มและระบุเครื่องที่มีตำหนิแยกต่างหาก

## ปัจจัยที่ใช้ประเมินราคาโน๊ตบุ๊ค

โดยสรุปควรดูร่วมกันอย่างน้อย:

### รุ่นและ Generation

ช่วยบอกอายุและตำแหน่งของสินค้า

### CPU

มีผลต่อประสิทธิภาพและตลาดของเครื่อง

### GPU

สำคัญมากกับ Gaming Notebook และ Workstation

### RAM และ SSD

มีผลต่อความพร้อมใช้งานและสเปกของชุด

### หน้าจอ

ความละเอียด Refresh Rate และสภาพ Panel มีผลแตกต่างกัน

### Battery

สภาพ Battery มีผลต่อการใช้งานแบบพกพา

### ตัวเครื่อง

บานพับ ฝา Keyboard Touchpad และพอร์ตควรอยู่ในสภาพที่ตรวจสอบได้

### อุปกรณ์

Adapter และอุปกรณ์เฉพาะรุ่นมีผลต่อความครบของชุด

### ประวัติซ่อม

ช่วยประเมินความเสี่ยงของเครื่อง

### ตลาดของรุ่น

รุ่นที่ยังมีผู้ใช้ต้องการอาจมีมูลค่าต่างจากเครื่องที่ถูกทดแทนไปแล้ว

## ขั้นตอนเช็กราคาโน๊ตบุ๊คก่อนขาย

### 1. ส่งรุ่น

หากไม่ทราบ ให้ส่งรูปป้ายใต้เครื่องหรือข้อมูลระบบ

### 2. ส่งสเปก

อย่างน้อย:

**CPU + RAM + SSD + GPU**

### 3. ส่งรูป

ถ่ายตัวเครื่องจริงทุกด้านและจุดตำหนิ

### 4. แจ้งสภาพ

เช่น

- เปิดติด
- จอปกติ
- Battery เสื่อม
- ไม่มี Adapter
- Keyboard มีปัญหา
- เคยซ่อม

### 5. ประเมินเบื้องต้น

ใช้รุ่น สเปก และสภาพประกอบกัน

### 6. ตัดสินใจ

สามารถพิจารณาก่อนว่าจะขายหรือเก็บเครื่องไว้

### 7. ส่งมอบและตรวจเครื่อง

เมื่อเลือกขายแล้วจึงตกลงวิธีส่งหรือนัดหมาย และตรวจสภาพจริงก่อนซื้อขาย

## อยู่ต่างจังหวัดสามารถเริ่มเช็กราคาอย่างไร

ไม่จำเป็นต้องเดินทางพร้อมเครื่องเพื่อถามราคาก่อน

สามารถเริ่มจากส่งข้อมูลออนไลน์:

## คำถามที่พบบ่อยเกี่ยวกับการรับซื้อโน๊ตบุ๊ค

### รับซื้อโน๊ตบุ๊คมือสองยี่ห้ออะไรบ้าง?

สามารถส่งโน๊ตบุ๊คหลายยี่ห้อมาประเมินได้ เช่น ASUS, Acer, Lenovo, HP, Dell, MSI, Gigabyte, Microsoft Surface และแบรนด์อื่น โดยราคาจะพิจารณาจากรุ่น สเปก สภาพ และอุปกรณ์ของเครื่องจริง

### โน๊ตบุ๊คแบตเสื่อมหรือไม่มี Adapter ขายได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้งอาการแบตเตอรี่และระบุว่ามี Adapter หรือไม่ เนื่องจากต้นทุน Adapter และ Battery แตกต่างกันตามรุ่น

### Gaming Notebook ต้องส่งสเปกอะไรบ้าง?

อย่างน้อยควรส่งรุ่น CPU, RAM, SSD และ GPU โดยเฉพาะรุ่นการ์ดจอเต็ม เช่น RTX 3050, RTX 4060 หรือรุ่นอื่น พร้อมแจ้งสภาพหน้าจอ แบตเตอรี่ และ Adapter

### โน๊ตบุ๊คเปิดไม่ติดยังขายได้ไหม?

บางกรณียังสามารถประเมินตามสภาพได้ ควรส่งรุ่น สเปกที่ทราบ อาการก่อนเสีย และข้อมูลว่ามีไฟเข้าหรือเคยซ่อมหรือไม่ เพื่อพิจารณามูลค่าของเครื่องและชิ้นส่วนที่เหลือ

### ต้องล้างข้อมูลก่อนส่งรูปเช็กราคาหรือไม่?

ไม่จำเป็นต้องล้างข้อมูลเพียงเพื่อเช็กราคา ควรสำรองข้อมูลและล้างข้อมูลส่วนตัวเมื่อพร้อมส่งมอบเครื่องจริง
