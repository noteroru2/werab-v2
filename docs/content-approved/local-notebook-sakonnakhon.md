## อยู่ในสกลนครเริ่มเช็กราคาจากข้อมูลก่อนได้

ผู้ขายสามารถส่งข้อมูลเบื้องต้นก่อนการเดินทางหรือส่งมอบสินค้า

สิ่งที่ควรรู้คือ:

- เครื่องรุ่นอะไร
- สเปกปัจจุบัน
- Battery เป็นอย่างไร
- มีตำหนิอะไร
- อุปกรณ์ครบหรือไม่

หลังจากนั้นจึงค่อยพิจารณาขั้นตอนต่อไปตามพื้นที่และความเหมาะสม

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำในทุกพื้นที่ของจังหวัด

---

## Notebook รุ่นเก่าควรตรวจสเปกก่อนตัดสินใจซ่อม

เครื่องเก่าบางรุ่นอาจยังมีมูลค่าจาก:

- CPU
- RAM
- SSD
- GPU
- หน้าจอ
- อะไหล่
- สภาพโดยรวม

หากมีอาการ ไม่ควรรีบซ่อมทุกกรณี

ควรเช็กราคาตามสภาพก่อน แล้วเปรียบเทียบกับค่าใช้จ่าย

---

## CPU ต้องใช้รหัสรุ่นเต็ม

ตัวอย่าง:

**Intel Core i5-1135G7**

หรือ

**AMD Ryzen 5 5500U**

ช่วยแยก Generation ได้ดีกว่าคำว่า Core i5 หรือ Ryzen 5 อย่างเดียว

---

## Gaming Notebook ต้องแจ้ง GPU

หากเครื่องมี Dedicated GPU ควรระบุรุ่น

เพราะ Notebook Gaming ชื่อ Series เดียวกันอาจมีหลาย GPU Configuration

ควรแจ้ง Adapter ด้วย เพราะกำลังไฟของ Adapter อาจต่างกันตามรุ่น

---

## RAM และ SSD ที่เพิ่มภายหลังมีผลกับ Configuration

ควรแจ้งของที่ติดตั้งอยู่ในปัจจุบัน

ถ้าตั้งใจถอด SSD หรือ RAM บางส่วนเก็บไว้ ต้องแจ้งก่อนประเมิน

ราคาควรอิงสิ่งที่ขายจริง ไม่ใช่ Configuration ที่เคยมีในอดีต

---

## Battery เสื่อมกับระบบชาร์จเสียไม่เหมือนกัน

ควรแยกว่า:

- Battery หมดเร็ว
- Battery ไม่เก็บไฟ
- ชาร์จไม่เข้า
- Port หลวม
- Adapter มีปัญหา
- Battery บวม

หากยังไม่ทราบสาเหตุ ไม่ควรระบุว่าเป็นอะไหล่ชิ้นใดแน่นอน

---

## จอมีปัญหาควรถ่ายตอนเปิดเครื่อง

อาการที่ควรแจ้ง เช่น

- เป็นเส้น
- มีจุด
- แตก
- กระพริบ
- สีผิดปกติ
- ไม่มีภาพ

หากต่อ Monitor ภายนอกแล้วแสดงผลได้ ควรแจ้งข้อมูลนี้ประกอบ

---

## Keyboard และบานพับมีผลต่อความพร้อมใช้งาน

ควรแจ้งหาก:

- ปุ่มเสีย
- ปุ่มหลุด
- Keyboard มีรอยน้ำ
- Touchpad มีปัญหา
- บานพับหลวม
- ฝาจอแยก
- Palmrest แตก

ความเสียหายเหล่านี้อาจทำให้ต้นทุนการซ่อมต่างกัน

---

## เครื่องเคยซ่อมต้องแจ้งหรือไม่

ควรแจ้งเท่าที่ทราบ เช่น

- เปลี่ยน Battery
- เปลี่ยนจอ
- ซ่อม Mainboard
- เปลี่ยน SSD
- เพิ่ม RAM
- เปลี่ยน Keyboard
- ซ่อมบานพับ

ไม่ได้หมายความว่าเครื่องที่เคยซ่อมจะขายไม่ได้ แต่ช่วยอธิบายสภาพได้ชัดขึ้น

---

## เครื่องเปิดไม่ติดควรทดลองซ้ำไหม

หากไม่มีอาการอันตราย สามารถสังเกตข้อมูลพื้นฐานได้ เช่นไฟชาร์จหรือพัดลม

แต่หาก:

- มีกลิ่นไหม้
- Battery บวม
- ร้อนผิดปกติ
- มีร่องรอยของเหลว

ไม่ควรเปิดซ้ำหลายครั้งเพื่อทดสอบเพียงเพื่อขอราคา

---

## ข้อมูลส่วนตัวควรจัดการแยกจาก Hardware

สำหรับการประเมินเบื้องต้น ไม่ต้องให้:

- Password
- PIN
- OTP
- Recovery Key
- Email Password

เจ้าของควรสำรองและจัดการข้อมูลของตนเองก่อนส่งมอบจริง

สามารถแจ้งว่าไม่รวม SSD หากต้องการเก็บ Storage ไว้

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในสกลนคร

### Notebook รุ่นเก่าในสกลนครยังเช็กราคาได้ไหม?

ได้ ควรแจ้ง Model สเปก สภาพ Battery และอาการก่อน เพื่อเปรียบเทียบว่าควรขายตามสภาพหรือซ่อมก่อน

### Gaming Notebook ต้องส่ง Adapter ด้วยหรือไม่?

ควรแจ้งว่า Adapter เดิม เทียบ หรือไม่มี เพราะเป็นส่วนหนึ่งของ Configuration และความพร้อมใช้งาน โดยเฉพาะเครื่อง Gaming

### จอเป็นเส้นยังประเมินได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรถ่ายหน้าจอและแจ้งว่าต่อจอนอกใช้งานได้หรือไม่ถ้าเคยทดสอบ

### เครื่องเปิดไม่ติดต้องซ่อมก่อนขายไหม?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพก่อน แล้วเปรียบเทียบค่าใช้จ่ายและความเสี่ยงในการซ่อม

### ขายโดยไม่รวม SSD ได้หรือไม่?

สามารถแจ้งว่าไม่รวม SSD ได้ โดยราคาต้องอิง Configuration ที่ขายจริง
