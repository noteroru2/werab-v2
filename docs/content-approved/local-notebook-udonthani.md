## คำถามที่พบบ่อยเกี่ยวกับการขาย Notebook ในอุดรธานี

### มี Notebook หลายเครื่องจากสำนักงานส่งรายการมาก่อนได้ไหม?

ได้ ควรแบ่งตาม Model, CPU, RAM, SSD, จำนวนและสภาพ หาก Configuration ต่างกันควรแยกเป็นคนละกลุ่ม

### เครื่องรุ่นเดียวกันแต่ RAM ต่างกันควรรวมกันไหม?

ควรแยก Configuration เพราะ Hardware ที่ติดตั้งจริงต่างกันและไม่ควรใช้เครื่องหนึ่งแทนทั้งหมด

### ขายเครื่องบริษัทโดยไม่รวม SSD ได้ไหม?

สามารถแจ้งว่าไม่รวม SSD ได้ และไม่จำเป็นต้องเปิดเผยข้อมูลภายในเพื่อประเมิน Hardware

### Notebook ที่เปิดไม่ติดรวมอยู่ในล็อตได้ไหม?

ได้ แต่ควรแยกสถานะจากเครื่องปกติและแจ้ง Model สเปกที่ทราบ รวมถึงอาการก่อนเสีย

### Adapter มีไม่ครบทุกเครื่องยังประเมินได้ไหม?

ได้ ควรแจ้งจำนวน Adapter ที่มีจริง ไม่จำเป็นต้องซื้อเพิ่มให้ครบก่อนเช็กราคา
