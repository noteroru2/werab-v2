# รับซื้อสินค้าไอทีมือสอง เลือกประเภทสินค้าที่ต้องการขาย
หากยังไม่แน่ใจ สามารถเริ่มจาก [เช็กราคาก่อนขาย](/เช็กราคาก่อนขาย/) โดยแจ้งอาการปัจจุบันก่อน


---


## ขั้นตอนเริ่มขายสินค้า


### 1. เลือกประเภทสินค้า


เข้าไปดูหน้าหมวดที่ตรงกับสินค้าของคุณ เพื่อดูว่าควรเตรียมข้อมูลอะไร


### 2. ส่งข้อมูล


โดยทั่วไปควรมี:


**รุ่น + สเปก + รูป + สภาพ + อุปกรณ์**


### 3. เช็กราคาเบื้องต้น


ใช้ข้อมูลสินค้าและสภาพจริงประกอบการประเมิน


### 4. ตัดสินใจ


การส่งข้อมูลมาสอบถามไม่ได้หมายความว่าต้องขายทันที


สามารถพิจารณาราคาและเงื่อนไขก่อน


### 5. ตกลงวิธีส่งหรือนัดหมาย


หลังตัดสินใจขายจึงตกลงวิธีส่งมอบที่เหมาะกับสินค้าและพื้นที่


### 6. ตรวจสินค้าจริงและซื้อขาย


ตรวจรุ่น สเปก สภาพ และอุปกรณ์ให้ตรงกับข้อมูลที่ใช้ประเมินก่อนดำเนินการซื้อขาย


[ดูวิธีขายสินค้า](/วิธีขาย/)

## ถ้ามีสินค้าไอทีหลายชิ้น


หากมีหลายรายการ ไม่จำเป็นต้องส่งข้อความแยกทีละชิ้น


สามารถจัดข้อมูลเป็นรายการ เช่น


1. ยี่ห้อ / รุ่น
2. สเปก
3. จำนวน
4. สภาพ
5. อุปกรณ์
6. รูปสินค้า


กรณีคอมพิวเตอร์ Notebook หรืออุปกรณ์องค์กรหลายเครื่อง การมีรายการสรุปจะช่วยให้ตรวจข้อมูลได้สะดวกกว่า
