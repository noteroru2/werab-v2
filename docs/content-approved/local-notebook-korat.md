- รุ่น

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ของนครราชสีมา

ตัวอย่างข้อมูลที่ควรแจ้ง:

## หน้าจอ Gaming มีรายละเอียดมากกว่าแค่ขนาด

หากทราบสามารถแจ้ง:

- Resolution
- Refresh Rate
- ขนาดจอ

พร้อมสภาพ:

- จุด
- เส้น
- กระพริบ
- Dead Pixel
- รอย
- Panel แตก

ไม่ควรคาดเดาสเปกจอหากยังไม่ได้ตรวจรุ่นเต็ม

---

## Adapter ของ Gaming Notebook ควรแจ้งด้วย

Adapter อาจมีกำลังไฟต่างกันตาม Configuration

ควรแจ้งว่า:

- Adapter เดิม
- Adapter เทียบ
- ไม่มี Adapter
- สายมีตำหนิ
- ชาร์จไม่ปกติ

ไม่จำเป็นต้องซื้อ Adapter ใหม่ก่อนเช็กราคา

---

## เครื่องทำงานและ Mobile Workstation ประเมินต่างจาก Gaming บางกรณี

หากเป็นเครื่องสำหรับงาน:

- CAD
- 3D
- Video
- Engineering
- Workstation

ควรแจ้ง Configuration เต็มโดยเฉพาะ CPU, GPU, RAM และ Storage

ไม่ควรใช้เพียงรูปลักษณ์หรือขนาดตัวเครื่องเป็นฐานประเมิน

---

## RAM และ SSD ที่เพิ่มภายหลังควรแจ้งปัจจุบัน

หากเครื่องเดิมมี RAM 16GB แต่เพิ่มเป็น 32GB ให้แจ้ง 32GB

ถ้า SSD เดิมถูกเปลี่ยน ให้แจ้ง Drive ที่รวมขายจริง

หากจะเก็บ SSD ไว้ควรแจ้งก่อนประเมิน

---

## Battery และระบบชาร์จต้องแยกอาการ

Battery หมดเร็วไม่เหมือนกับชาร์จไม่เข้า

ควรแจ้งว่า:

- Battery Health
- ใช้งานได้กี่นาทีหรือชั่วโมงโดยประมาณ
- ชาร์จเข้าไหม
- Port หลวมหรือไม่
- Adapter มีอาการหรือไม่

ไม่ควรวินิจฉัยว่าเป็น Mainboard หรือ Battery หากยังไม่ได้ตรวจ

---

## เครื่องมีอาการตอนเล่นเกมควรแจ้ง

- ร้อนผิดปกติ

ไม่จำเป็นต้อง Stress Test หนักซ้ำเพื่อถามราคา หากเครื่องแสดงอาการไม่เสถียรอยู่แล้ว

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในโคราช

### Gaming Notebook ต้องส่งสเปกอะไรบ้าง?

ควรส่ง Model, CPU, GPU, RAM, SSD, Battery และ Adapter เพราะ Gaming Series เดียวกันอาจมีหลาย Configuration

### ไม่มี Adapter ยังเช็กราคาได้ไหม?

ได้ ควรแจ้งว่าไม่มี Adapter ตั้งแต่ต้น ไม่จำเป็นต้องซื้อใหม่ก่อนทราบว่าคุ้มกับมูลค่าที่เพิ่มหรือไม่

### Notebook ดับเวลาเล่นเกมยังประเมินได้หรือไม่?

สามารถส่งข้อมูลตามสภาพได้ ควรแจ้งอาการและประวัติซ่อม ไม่จำเป็นต้อง Stress Test หนักซ้ำเพื่อขอราคา

### เครื่องเคยเพิ่ม RAM และ SSD ต้องแจ้งสเปกเดิมหรือปัจจุบัน?

ควรแจ้ง Configuration ปัจจุบันและระบุสิ่งที่รวมขายจริง

### ขายเครื่องโดยเก็บ SSD ไว้ได้ไหม?

สามารถแจ้งว่าไม่รวม SSD ได้ โดยราคาต้องประเมินจาก Hardware ที่ขายจริง
