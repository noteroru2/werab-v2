## อยู่ในอุบลราชธานี ไม่จำเป็นต้องยกเครื่องมาเพื่อถามราคาก่อน

หากยังอยู่ในขั้นเช็กราคา สามารถเริ่มจากส่งข้อมูลและรูปก่อน

- อำเภอเมืองอุบลราชธานี
- วารินชำราบ
- เดชอุดม
- พิบูลมังสาหาร
- ตระการพืชผล
- เขื่องใน
- ม่วงสามสิบ
- น้ำยืน
- และพื้นที่อื่นในจังหวัดอุบลราชธานี

การกล่าวถึงพื้นที่เหล่านี้ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้ออยู่ทุกอำเภอ

จุดประสงค์คือให้ผู้ขายสามารถเริ่มเช็กราคาได้ก่อน แล้วจึงค่อยพิจารณาวิธีส่งมอบหรือนัดหมายตามพื้นที่และความเหมาะสม

## CPU มีผลต่อราคาอย่างไร

CPU เป็นหนึ่งในข้อมูลหลักที่ใช้แยก Generation และระดับของเครื่อง

ควรแจ้งรุ่นเต็ม เช่น

- Intel Core i5-12450H
- Intel Core i7-12700H
- Intel Core Ultra รุ่นต่าง ๆ
- AMD Ryzen 5 7535HS
- AMD Ryzen 7 7840HS
- หรือรุ่นอื่น

คำว่า “Core i7” หรือ “Ryzen 7” อย่างเดียวอาจยังไม่พอ เพราะแต่ละ Generation มีประสิทธิภาพและอายุของ Platform ต่างกัน

## RAM และ SSD ควรแจ้งเท่าไร

## ไม่มี Adapter ยังเช็กราคาได้ไหม

ได้

ควรแจ้งตั้งแต่ต้นว่า:

**ไม่มี Adapter**

หรือ

**มี Adapter เทียบ**

หรือ

**มี Adapter เดิม**

Adapter มีผลต่อความครบและความพร้อมใช้งาน แต่ไม่ใช่ปัจจัยเดียวในการประเมิน

ไม่จำเป็นต้องรีบซื้อ Adapter ใหม่ก่อนรู้ว่าต้นทุนคุ้มกับมูลค่าที่เพิ่มหรือไม่

## ขายเครื่องโดยไม่รวม SSD ได้ไหม

บางกรณีสามารถแจ้งตั้งแต่ต้นว่า:

**ไม่รวม SSD**

ได้

โดยเฉพาะเมื่อมีข้อมูลสำคัญหรือผู้ขายต้องการเก็บ Drive ไว้

ราคาจะต้องพิจารณาจาก Configuration ที่ขายจริง

ไม่ควรแจ้งสเปกว่ามี SSD รวมขาย หากตั้งใจถอดออกก่อนส่งมอบ

## เครื่องจากบริษัทหรือสำนักงานในอุบลมีหลายเครื่องควรทำอย่างไร

หากมี Notebook หลายเครื่อง ไม่จำเป็นต้องส่งรายละเอียดแบบข้อความยาวทีละเครื่อง

สามารถจัดเป็นตาราง เช่น

| รุ่น | CPU | RAM | SSD | จำนวน | สภาพ |
|---|---|---|---|---|---|
| รุ่น... | i5-... | 8GB | 256GB | 5 | ใช้งานได้ |
| รุ่น... | i5-... | 16GB | 512GB | 3 | Battery เสื่อม |
| รุ่น... | ไม่ทราบ | ไม่ทราบ | ไม่ทราบ | 2 | เปิดไม่ติด |

หากมี Asset Tag ภายในบริษัท สามารถใช้ช่วยจัดรายการได้โดยไม่ต้องเปิดเผยข้อมูลภายในที่ไม่เกี่ยวข้อง

## ผู้ขายในอำเภอเมืองอุบลราชธานีและวารินชำราบเริ่มอย่างไร

หากอยู่บริเวณเมืองอุบลราชธานีหรือวารินชำราบ สามารถเริ่มจากส่งข้อมูลเครื่องก่อนเช่นเดียวกัน

สิ่งสำคัญคือไม่จำเป็นต้องเดินทางพร้อม Notebook เพียงเพื่อถามราคาเบื้องต้น

**Model + สเปก + รูป + Battery + อาการ + อุปกรณ์**

ก่อน

เมื่อมีข้อมูลเพียงพอแล้วจึงค่อยพิจารณารูปแบบการตรวจสินค้าและส่งมอบตามความเหมาะสม

## ปัจจัยหลักที่ใช้ประเมินโน๊ตบุ๊คมือสองในอุบลราชธานี

### รุ่นและ Generation

ใช้แยกระดับของเครื่องและอายุของ Platform

### CPU

ต้องดูรุ่นเต็ม ไม่ใช่เพียง Core i5 หรือ Ryzen 5

### GPU

สำคัญมากสำหรับ Gaming Notebook และเครื่องงานกราฟิก

### RAM

ดูความจุและ Configuration ปัจจุบัน

### SSD

ดูความจุและสิ่งที่รวมขายจริง

### หน้าจอ

ดูความละเอียด Refresh Rate และสภาพ

### Battery

ดูอาการและสุขภาพเท่าที่ตรวจได้

### Keyboard และ Touchpad

มีผลต่อความพร้อมใช้งาน

### ตัวเครื่องและบานพับ

ดูรอย แตก บุบ และความแข็งแรงของโครง

### ประวัติซ่อม

ช่วยอธิบายความเสี่ยงของเครื่อง

### Adapter และอุปกรณ์

มีผลต่อความครบ

### ประกัน

หากยังเหลือและตรวจสอบได้ สามารถใช้เป็นข้อมูลประกอบ

### ตลาดของรุ่น

ความต้องการของ Notebook แต่ละรุ่นเปลี่ยนแปลงตามเวลา

## ขั้นตอนเช็กราคาโน๊ตบุ๊คในอุบลก่อนขาย

### 1. ส่ง Brand และ Model

แจ้งรุ่นเต็มเท่าที่ทราบ

### 2. ส่งสเปก

อย่างน้อย:

**CPU + RAM + SSD**

หากเป็น Gaming Notebook เพิ่ม:

**GPU**

### 3. ส่งรูปเครื่อง

ควรถ่าย:

- ฝาหน้า
- หน้าจอ
- Keyboard
- ด้านล่าง
- Port
- Adapter
- จุดตำหนิ

### 4. แจ้ง Battery

ระบุอาการใช้งานหรือ Battery Health ถ้ามีข้อมูล

### 5. แจ้งอาการ

เช่น จอมีเส้น Keyboard เสีย เปิดไม่ติด หรือมีปัญหาอื่น

### 6. แจ้งประวัติ

เคยซ่อม ตก โดนน้ำ หรือเปลี่ยนอุปกรณ์หรือไม่

### 7. แจ้งอุปกรณ์

เช่น Adapter, Box หรืออุปกรณ์อื่นที่รวมขาย

### 8. ประเมินเบื้องต้น

พิจารณารุ่น สเปก สภาพและอุปกรณ์ร่วมกัน

### 9. ตัดสินใจ

ผู้ขายสามารถพิจารณาก่อนว่าจะขาย ซ่อม หรือเก็บเครื่องไว้

### 10. ตรวจเครื่องและซื้อขาย

ตรวจรุ่น สเปก สภาพ และสิ่งที่รวมขายให้ตรงกับข้อมูลที่ใช้ประเมินก่อนดำเนินการซื้อขาย

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในอุบลราชธานี

### อยู่ต่างอำเภอในอุบลราชธานีสามารถเช็กราคาก่อนได้ไหม?

สามารถเริ่มจากส่งรุ่น สเปก รูป สภาพ Battery และอุปกรณ์เพื่อประเมินเบื้องต้นก่อน แล้วจึงค่อยพิจารณาวิธีตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม ไม่จำเป็นต้องเดินทางพร้อมเครื่องเพียงเพื่อถามราคาเบื้องต้น

### Gaming Notebook ในอุบลต้องส่งสเปกอะไรบ้าง?

ควรแจ้ง Model, CPU, GPU, RAM, SSD, หน้าจอถ้าทราบ, Battery และ Adapter โดยเฉพาะ GPU ควรแจ้งรุ่นเต็มเพราะมีผลต่อ Configuration และการประเมินเครื่อง Gaming

### โน๊ตบุ๊คเปิดไม่ติดหรือ Battery เสื่อมยังขายได้ไหม?

บางกรณีสามารถส่งมาประเมินตามสภาพได้ ควรแจ้งรุ่น สเปก อาการ ไฟสถานะ Adapter ประวัติซ่อม และสภาพเครื่องตามจริง เครื่องที่ไม่สามารถทดสอบได้จะมีความไม่แน่นอนสูงกว่าเครื่องปกติ

### ไม่มี Adapter หรือไม่มีกล่องขายได้ไหม?

สามารถส่งมาประเมินได้ ควรแจ้งอุปกรณ์ที่มีจริง ไม่จำเป็นต้องซื้อ Adapter หรือกล่องใหม่ก่อนเช็กราคา เพราะต้องเปรียบเทียบต้นทุนกับมูลค่าที่เพิ่มขึ้นก่อน

### มี Notebook หลายเครื่องจากบริษัทในอุบลควรส่งข้อมูลอย่างไร?

ควรจัดรายการตามรุ่น CPU RAM SSD จำนวนและสภาพ หากแต่ละกลุ่มมี Configuration ต่างกันควรแยกเป็นคนละรายการ และไม่จำเป็นต้องเปิดเผยข้อมูลบริษัทที่ไม่เกี่ยวข้องกับการประเมิน Hardware
