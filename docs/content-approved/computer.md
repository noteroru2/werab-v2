## การ์ดจอเป็นหนึ่งในชิ้นส่วนสำคัญของ Gaming PC

สำหรับ Gaming PC การ์ดจออาจเป็นชิ้นส่วนที่มีมูลค่าสูงที่สุดตัวหนึ่งในเครื่อง

ควรแจ้งรุ่นเต็ม เช่น

- GTX 1660 Super
- RTX 2060
- RTX 3060
- RTX 3070
- RTX 4060
- RTX 4070
- RX 6600
- RX 6700 XT
- RX 7600
- หรือรุ่นอื่น

ถ้าทราบยี่ห้อและรุ่นย่อยของการ์ด เช่น ASUS, MSI, Gigabyte, GALAX หรือ Sapphire สามารถแจ้งเพิ่มได้

การบอกเพียงว่า “RTX” หรือ “การ์ดจอ 8GB” ยังไม่เพียงพอสำหรับการประเมิน

## RAM ต้องดูทั้งความจุและประเภท

ข้อมูลที่ควรแจ้ง เช่น

- RAM 8GB
- RAM 16GB
- RAM 32GB
- RAM 64GB
- DDR4
- DDR5
- Bus หรือความเร็วถ้าทราบ
- จำนวนแถว

ตัวอย่าง:

`DDR4 16GB (8GB × 2) 3200MHz`

หรือ

`DDR5 32GB (16GB × 2)`

การเพิ่ม RAM มีผลต่อความพร้อมใช้งานของเครื่อง แต่ราคามือสองที่เพิ่มขึ้นไม่ได้จำเป็นต้องเท่ากับราคาที่ซื้อ RAM ใหม่มา

## SSD และพื้นที่เก็บข้อมูล

ควรแจ้งทั้งประเภทและความจุ เช่น

- NVMe 500GB
- NVMe 1TB
- SATA SSD 512GB
- HDD 1TB
- SSD + HDD

หากมี Storage หลายลูกควรแจ้งแยก

สำหรับ SSD ที่ใช้งานมานาน หากมีข้อมูลสุขภาพของ Drive ก็สามารถส่งประกอบได้ แต่ไม่จำเป็นสำหรับการถามราคาเบื้องต้นทุกกรณี

ก่อนส่งมอบเครื่องจริงควรสำรองและล้างข้อมูลส่วนตัวออกจาก Storage ที่ขายไปพร้อมเครื่อง

## Power Supply ไม่ควรมองข้าม

PSU เป็นชิ้นส่วนที่มีผลต่อความสมบูรณ์และความน่าเชื่อถือของเครื่อง

ควรแจ้ง:

- Brand
- Model
- Watt
- 80 PLUS Rating ถ้ามี
- อายุโดยประมาณ
- ประกันถ้ายังเหลือ

ตัวอย่าง:

`750W 80+ Bronze`

ข้อมูลเพียง “750W” อาจยังไม่พอ เพราะ Power Supply ต่างแบรนด์และต่างระดับมีต้นทุนไม่เท่ากัน

## Case และระบบระบายความร้อนมีผลแค่ไหน

Case และชุดระบายความร้อนมีผลต่อความครบของชุด แต่โดยทั่วไปควรประเมินหลังชิ้นส่วนหลักอย่าง CPU และ GPU

ข้อมูลที่แจ้งเพิ่มได้ เช่น

- Case รุ่นอะไร
- พัดลมกี่ตัว
- Air Cooler
- Liquid Cooler
- ขนาดหม้อน้ำ
- RGB Controller
- Tempered Glass
- สภาพกระจกและตัว Case

Case ที่มีรอยใช้งานกับ Case ที่กระจกแตกหรือโครงสร้างเสียหายควรแจ้งต่างกัน

## คอมซื้อมาแพง ทำไมราคามือสองไม่เท่าราคาที่เคยจ่าย

ราคาที่ซื้อใหม่ในอดีตเป็นข้อมูลหนึ่ง แต่ไม่ใช่ตัวกำหนดราคามือสองปัจจุบัน

ต้องดูร่วมกับ:

- อายุของชิ้นส่วน
- รุ่นใหม่ที่ออกมาทดแทน
- ประสิทธิภาพ
- ราคาตลาดมือสอง
- ประกันที่เหลือ
- สภาพ
- ความต้องการของผู้ซื้อ
- ความเสี่ยงของอุปกรณ์

ตัวอย่างเช่น การ์ดจอที่เคยมีราคาใหม่สูงในช่วงหนึ่ง อาจมีราคามือสองลดลงมากเมื่อมี Generation ใหม่หรือราคาตลาดเปลี่ยน

ดังนั้นควรประเมินจากมูลค่าปัจจุบันของชิ้นส่วน ไม่ใช่รวมราคาซื้อเดิมทั้งหมด

## ควรขายยกเครื่องหรือแยกชิ้น

ไม่มีคำตอบเดียวสำหรับทุกเครื่อง

### ขายยกเครื่อง

ข้อดีคือ

- สะดวก
- จัดการครั้งเดียว
- ไม่ต้องถอดอุปกรณ์
- ไม่เหลือชิ้นส่วนที่ขายยาก

### แยกชิ้น

บางเครื่องอาจมีชิ้นส่วนบางตัวที่มีตลาดแยกชัด เช่น

- GPU
- CPU
- RAM
- SSD

แต่ต้องพิจารณาด้วยว่าชิ้นส่วนที่เหลือหลังจากแยกของมูลค่าสูงออกแล้วขายต่อได้ง่ายหรือไม่

ก่อนถอดเครื่อง แนะนำให้เช็กราคาทั้งแบบ **ยกชุด** และดูมูลค่าชิ้นส่วนสำคัญประกอบกันก่อน

## Gaming PC ก่อนขายควรทดสอบอะไร

ถ้าเครื่องยังเปิดได้ ควรตรวจพื้นฐานก่อนส่งข้อมูล

### เปิดเครื่องและ Boot

ตรวจว่าเปิดติดและเข้า Windows ได้ปกติหรือไม่

### CPU

สังเกตอุณหภูมิและอาการผิดปกติ

### GPU

ตรวจว่า Windows มองเห็นการ์ดจอและสามารถใช้งานได้

### RAM

ดูว่าระบบมองเห็นความจุครบ

### Storage

ตรวจว่า SSD หรือ HDD ที่แจ้งไว้แสดงครบ

### พอร์ต

ลอง USB, LAN, Audio และพอร์ตสำคัญที่ใช้งานอยู่

### พัดลมและระบบระบายความร้อน

ตรวจว่าพัดลมหมุนและไม่มีเสียงผิดปกติชัดเจน

ไม่จำเป็นต้องรัน Stress Test หนักเพื่อถามราคาเบื้องต้น หากเครื่องมีอาการผิดปกติควรแจ้งตามจริง

## วิธีดูสเปกคอมใน Windows

ถ้าเครื่องเปิด Windows ได้ สามารถเริ่มจาก Task Manager

กด:

`Ctrl + Shift + Esc`

จากนั้นเลือก Performance

จะเห็นข้อมูล เช่น

- CPU
- Memory
- Disk
- GPU

แต่ Task Manager อาจไม่ได้แสดง Mainboard และ PSU

Mainboard สามารถตรวจจาก System Information หรือโปรแกรมตรวจ Hardware

ส่วน PSU มักต้องดูป้ายที่ตัว Power Supply ภายใน Case

ถ้าไม่มั่นใจ สามารถส่งรูปภายในเครื่องมาเพื่อช่วยระบุชิ้นส่วนเบื้องต้นได้

## คอมหลายเครื่องหรือคอมบริษัท

หากมี Desktop หลายเครื่อง ไม่จำเป็นต้องส่งข้อมูลซ้ำทีละเครื่องหากสเปกเหมือนกัน

สามารถจัดเป็นรายการ:

| รุ่น/ชุด | CPU | RAM | SSD | GPU | จำนวน | สภาพ |
|---|---|---|---|---|---|---|
| ชุด A | i5-... | 16GB | 512GB | Intel | 10 | ใช้งานได้ |
| ชุด B | Ryzen... | 8GB | 256GB | ไม่มี | 5 | มีตำหนิ |

หากเครื่องแต่ละกลุ่มมีสภาพต่างกัน ควรแยกจำนวนเครื่องที่ใช้งานได้และเครื่องที่มีปัญหา

## ก่อนขายคอมควรล้างข้อมูลอย่างไร

ข้อมูลส่วนตัวมักอยู่ใน SSD หรือ HDD

ก่อนส่งมอบควร:

1. Backup ข้อมูลสำคัญ
2. ตรวจ Desktop
3. ตรวจ Documents
4. ตรวจ Downloads
5. ตรวจรูปและไฟล์งาน
6. ออกจากบัญชีสำคัญ
7. ตรวจ Browser

หากมี Drive ที่ไม่ต้องการขาย สามารถแจ้งตั้งแต่ตอนประเมินว่า **ขายเครื่องโดยไม่รวม Storage**

อย่าลบข้อมูลก่อน Backup เสร็จ

## ปัจจัยหลักที่ใช้ประเมินราคาคอมมือสอง

โดยสรุปประกอบด้วย

### CPU

ดูรุ่น Generation และประสิทธิภาพ

### GPU

สำคัญมากสำหรับ Gaming PC

### RAM

ดูความจุ ประเภท และจำนวน

### Storage

ดูชนิด ความจุ และจำนวน Drive

### Mainboard

ดู Platform และระดับของบอร์ด

ดู Brand, Model, Watt และสภาพ

ดูความสมบูรณ์และอุปกรณ์ภายใน

### อายุและประกัน

ประกันที่เหลืออาจเป็นข้อมูลประกอบ

### สภาพการทำงาน

เครื่องสมบูรณ์กับเครื่องที่มีอาการต้องประเมินต่างกัน

### ตลาดปัจจุบัน

ราคาชิ้นส่วนมือสองเปลี่ยนได้ตาม Generation และความต้องการ

## ขั้นตอนเช็กราคาคอมก่อนขาย

### 1. ส่งสเปกหลัก

อย่างน้อย:

**CPU + GPU + RAM + SSD**

ถ้าทราบให้เพิ่ม:

**Mainboard + PSU**

### 2. ส่งรูป

ถ่าย:

- ด้านหน้า
- ด้านข้าง
- ภายใน Case
- ด้านหลัง
- จุดตำหนิ

### 3. แจ้งสภาพ

ระบุว่า:

- เปิดติดหรือไม่
- เข้า Windows ได้ไหม
- มีอาการอะไร
- เคยซ่อมหรือไม่
- มีประกันเหลือไหม

### 4. แจ้งของที่ขายรวม

เช่น:

- จอ
- Keyboard
- Mouse
- Wi-Fi
- อุปกรณ์อื่น

### 5. ประเมินเบื้องต้น

ดูสเปกและสภาพร่วมกัน

### 6. พิจารณา

ผู้ขายสามารถเปรียบเทียบและตัดสินใจก่อนขายได้

### 7. ตรวจเครื่องจริง

เมื่อเลือกขาย จึงตรวจ Hardware และสภาพจริงก่อนดำเนินการซื้อขาย

## คำถามที่พบบ่อยเกี่ยวกับการรับซื้อคอม

### รับซื้อคอมประกอบและ Gaming PC ไหม?

สามารถส่งคอมประกอบ Desktop PC และ Gaming PC มาประเมินได้ โดยควรแจ้ง CPU, GPU, RAM, SSD, Mainboard, PSU และสภาพเครื่อง เพื่อพิจารณามูลค่าจากชิ้นส่วนที่ติดตั้งจริง

### ขายคอมยกชุดหรือแยกชิ้นดีกว่ากัน?

ขึ้นอยู่กับสเปกและมูลค่าของชิ้นส่วนแต่ละตัว การขายยกชุดสะดวกกว่า ส่วนการแยกชิ้นอาจเหมาะกับบางเครื่องที่มีอุปกรณ์มูลค่าสูง ควรเปรียบเทียบมูลค่าทั้งสองแบบก่อนถอดเครื่อง

### คอมมีปัญหาหรือเปิดไม่ติดขายได้ไหม?

สามารถส่งข้อมูลมาประเมินตามสภาพได้ ควรแจ้งสเปกที่ทราบ อาการที่พบ และประวัติการซ่อมหากมี เครื่องที่เสียหนักอาจต้องประเมินจากมูลค่าชิ้นส่วนที่ยังเหลืออยู่

### ขายคอมโดยไม่รวม SSD หรือ HDD ได้ไหม?

สามารถแจ้งตั้งแต่ตอนประเมินว่าไม่รวม Storage ได้ โดยราคาจะพิจารณาจากอุปกรณ์ที่ขายจริง และช่วยให้เจ้าของสามารถเก็บ Drive ที่มีข้อมูลส่วนตัวไว้ได้

### ต้องส่งสเปกอะไรเพื่อเช็กราคาคอม?

อย่างน้อยควรมี CPU, GPU, RAM และ SSD หากทราบควรเพิ่ม Mainboard, PSU พร้อมรูปภายใน Case สภาพเครื่อง และรายการอุปกรณ์ที่ขายรวม
