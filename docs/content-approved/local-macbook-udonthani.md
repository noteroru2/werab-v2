## อยู่ในอุดรธานีสามารถส่งข้อมูล MacBook มาเช็กราคาก่อนได้

สามารถเริ่มจากข้อมูลเครื่องและรูปก่อน โดยไม่จำเป็นต้องเดินทางพร้อม MacBook เพียงเพื่อถามราคาเบื้องต้น

หลังทราบรุ่นและสภาพแล้วจึงค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

หน้านี้ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ในจังหวัดอุดรธานี

## MacBook Air และ Pro ต้องระบุ Generation

ควรแจ้งให้ชัดว่าเป็นรุ่นใด เช่น:

- Intel MacBook Air
- Intel MacBook Pro
- MacBook Air M1
- MacBook Air M2
- MacBook Pro M1
- MacBook Pro M2
- M3
- M4
- หรือ Generation อื่น

ไม่ควรใช้เพียงคำว่า:

**MacBook Air**

หรือ:

**MacBook Pro**

เพราะมีหลายปีและหลาย Platform

---

## Apple Silicon กับ Intel ต้องแยกให้ถูก

MacBook Intel และ Apple Silicon มี Hardware Architecture ต่างกัน

หากไม่แน่ใจสามารถดูจาก:

**About This Mac**

หรือส่งรูปข้อมูล Model

ไม่จำเป็นต้องส่งรหัสผ่านของเครื่องเพื่อแจ้งข้อมูล Hardware

---

## RAM และ Storage เป็นส่วนสำคัญของ Configuration

ตัวอย่าง:

**MacBook Air M2 / RAM 8GB / SSD 256GB**

กับ:

**MacBook Air M2 / RAM 16GB / SSD 512GB**

เป็นคนละ Configuration

ควรแจ้ง RAM และ Storage ตามเครื่องจริง

---

## Battery Health และ Cycle Count ควรส่งถ้าตรวจได้

ข้อมูลที่ช่วยประกอบ เช่น:

- Maximum Capacity
- Cycle Count
- Battery Condition
- Service Recommended
- อาการใช้งานจริง

Battery Cycle ไม่ใช่ข้อมูลเดียวที่ใช้ประเมิน แต่ช่วยอธิบายการใช้งานที่ผ่านมา

หาก Battery บวม ไม่ควรกด Trackpad ฝาล่าง หรือใช้งานหนักโดยไม่จำเป็น

---

- Trackpad มีอาการจาก Battery บวม
- Touch Bar มีปัญหาในรุ่นที่มี
- Backlight Keyboard มีอาการ

## คำถามที่พบบ่อยเกี่ยวกับการขาย MacBook ในอุดรธานี

### MacBook Air หรือ Pro ต้องบอกปีหรือชิปไหม?

ควรแจ้ง Generation ปีหรือชิปเท่าที่ตรวจได้ เพราะชื่อ Air หรือ Pro ครอบคลุมหลายรุ่นและหลาย Configuration

### Battery Cycle สูงยังประเมินได้ไหม?

ได้ Cycle Count เป็นข้อมูลประกอบ ควรดูร่วมกับ Maximum Capacity อาการใช้งานจริงและสภาพเครื่อง

### MacBook เคยเปลี่ยน Battery หรือจอยังขายได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้งประวัติที่ทราบและสภาพปัจจุบัน

### ไม่มี Charger ยังเช็กราคาได้หรือไม่?

ได้ ควรแจ้งว่าไม่มี Charger ตั้งแต่ต้น ไม่จำเป็นต้องซื้อใหม่ก่อนทราบว่าคุ้มกับมูลค่าที่เพิ่มขึ้นหรือไม่

### ต้องส่ง Apple ID Password เพื่อถามราคาไหม?

ไม่ต้อง และไม่ควรส่ง Apple ID Password, Mac Login Password, PIN, OTP หรือ Recovery Key เพื่อขอราคาประเมิน
