## หน้าขอนแก่นนี้เป็น Intent ระดับจังหวัด

หน้า Local นี้ครอบคลุมคำค้นที่ระบุขอนแก่นในระดับจังหวัด

หาก Historical URL อื่นระบุพื้นที่ย่อยเฉพาะ เช่น อำเภอหนึ่งภายในขอนแก่น URL นั้นอาจมี Intent ของตัวเองและไม่ควรถูกรวมโดยอัตโนมัติ

ดังนั้นหน้านี้จะไม่ใส่รายชื่ออำเภอจำนวนมากเพียงเพื่อขยาย Keyword

---

## Model และ Generation เป็นข้อมูลแรกที่ควรตรวจ

ควรส่งชื่อรุ่นเต็มจาก:

- ใต้เครื่อง
- BIOS
- System Information
- About
- กล่องเดิม

เพราะ Series เดียวกันอาจมีหลาย Generation

---

## Notebook ทั่วไปกับ Gaming Notebook ต้องดูข้อมูลต่างกันบางส่วน

Notebook ทั่วไปควรแจ้งอย่างน้อย:

- CPU
- RAM
- SSD
- Battery

Gaming Notebook ควรเพิ่ม:

- GPU
- Adapter
- หน้าจอถ้าทราบ

เพื่อแยก Configuration ให้ถูกต้อง

---

## CPU ต้องแจ้งรหัสเต็ม

เช่น:

**Intel Core i5-12450H**

หรือ

**AMD Ryzen 7 7735HS**

ไม่ควรแจ้งเพียง Core i5 หรือ Ryzen 7

Generation มีผลต่ออายุ Platform และความสามารถของเครื่อง

---

## RAM และ SSD ควรใช้ Configuration ปัจจุบัน

หากอัปเกรดแล้วให้แจ้งของที่อยู่ในเครื่องจริง

เช่น:

**RAM 16GB / SSD 512GB**

หากจะถอด SSD หรือ RAM บางส่วนออกก่อนขายต้องแจ้งตั้งแต่ก่อนประเมิน

---

## Battery ควรดูทั้ง Health และอาการ

หากระบบแสดง Health สามารถส่งได้

หากไม่แสดง ให้แจ้งว่า:

- ใช้งานได้ปกติ
- หมดเร็ว
- ไม่เก็บไฟ
- ต้องเสียบ Adapter
- เคยเปลี่ยน
- บวม

ถ้า Battery บวมควรหลีกเลี่ยงการใช้งานหนัก

---

## จอและตัวเครื่องควรส่งรูปหลายด้าน

ควรถ่าย:

- หน้าจอ
- Keyboard
- ฝาหลัง
- ด้านล่าง
- บานพับ
- Port
- Adapter

และถ่ายตำหนิแยกหากมี

---

## Notebook ที่ไม่มี Adapter ยังเช็กราคาได้

ควรแจ้งว่า:

**ไม่มี Adapter**

ตั้งแต่ต้น

ไม่จำเป็นต้องซื้อ Adapter ใหม่ก่อนทราบว่ามูลค่าที่เพิ่มขึ้นคุ้มกับต้นทุนหรือไม่

---

## เครื่องมีอาการหรือเปิดไม่ติด

สามารถเริ่มจากส่งข้อมูลตามที่ทราบ

เช่น:

- ไฟเข้าแต่ไม่เปิด
- เปิดแล้วดับ
- ไม่มีภาพ
- จอฟ้า
- จอกระพริบ
- Keyboard มีปัญหา

ไม่ควรวินิจฉัยสาเหตุเองหากยังไม่ได้ตรวจ

และหากมี Battery บวม กลิ่นไหม้ หรือความร้อนผิดปกติ ไม่ควรทดลองเปิดซ้ำหลายครั้ง

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในขอนแก่น

### หน้า Notebook ขอนแก่นต่างจากหน้าระดับอำเภออย่างไร?

หน้านี้รักษา Intent ระดับจังหวัดขอนแก่น ส่วน Historical URL ที่ระบุอำเภอเฉพาะจะรักษา Search Intent ของพื้นที่ย่อยนั้นหากได้รับการอนุมัติแยก

### Gaming Notebook ต้องแจ้ง GPU ไหม?

ควรแจ้งรุ่น GPU เต็ม รวมถึง CPU, RAM และ SSD เพราะชื่อ Series เดียวกันอาจมีหลาย Configuration

### Battery เสื่อมยังประเมินได้ไหม?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้ง Health หรืออาการและไม่จำเป็นต้องเปลี่ยนก่อนเช็กราคา

### เครื่องเปิดไม่ติดยังส่งข้อมูลได้หรือไม่?

ได้ ควรส่ง Model สเปกที่ทราบ รูป Adapter และอาการ แต่ไม่ควรเปิดซ้ำหลายครั้งหากมีอาการผิดปกติด้านไฟหรือ Battery

### ขายโดยไม่รวม SSD ได้ไหม?

สามารถแจ้งว่าไม่รวม SSD ได้ ราคาจะพิจารณาจาก Configuration ที่รวมขายจริง
