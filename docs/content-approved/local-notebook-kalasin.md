## Notebook ในกาฬสินธุ์เริ่มเช็กราคาจากข้อมูลเครื่องได้

หากยังไม่แน่ใจว่าจะขายหรือซ่อม สามารถเริ่มจากส่งข้อมูลโดยไม่จำเป็นต้องเดินทางพร้อมเครื่องเพื่อถามราคา

ควรเตรียม:

- Model
- สเปก
- Battery
- รูป
- Adapter
- อาการ
- ประวัติซ่อม

แล้วค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำในทุกพื้นที่ของจังหวัดกาฬสินธุ์

---

## Notebook ที่ใช้งานมาหลายปีควรตรวจ Configuration ปัจจุบัน

เครื่องที่ใช้งานมานานอาจผ่านการ:

- เพิ่ม RAM
- เปลี่ยน SSD
- เปลี่ยน Battery
- เปลี่ยน Keyboard
- ซ่อมจอ

ดังนั้นข้อมูลปัจจุบันสำคัญกว่าสเปกในใบโฆษณาตอนซื้อใหม่

---

## CPU ช่วยบอก Generation ของเครื่อง

ควรแจ้งรหัสเต็ม เช่น:

**Intel Core i5-10210U**

**Intel Core i5-1235U**

**AMD Ryzen 5 5500U**

แทนการแจ้งเพียง:

**Core i5**

เพราะ CPU คนละ Generation อาจมีประสิทธิภาพและอายุ Platform ต่างกัน

---

## Gaming Notebook ควรแจ้ง GPU และ Adapter

หากมี Dedicated GPU ควรแจ้งรุ่น เช่น:

- GTX Series
- RTX Series
- Radeon

รวมถึง Adapter ที่ใช้

Gaming Notebook บาง Series มีหลาย Configuration แม้ตัวเครื่องภายนอกใกล้เคียงกัน

---

## Battery เก่ากับเครื่องเสียต้องแยกกัน

Battery เสื่อมไม่ได้หมายความว่า Notebook ทั้งเครื่องเสีย

ควรแจ้งอาการ เช่น:

- Battery อยู่ได้ไม่นาน
- ต้องเสียบ Adapter
- Battery ไม่เก็บไฟ
- เครื่องชาร์จไม่เข้า
- Battery บวม

หากยังไม่ทราบสาเหตุของการชาร์จไม่เข้า ไม่ควรสรุปว่าเสีย Battery หรือ Mainboard โดยไม่ได้ตรวจ

---

## SSD มีข้อมูลสำคัญสามารถเก็บไว้ได้

หากไม่ต้องการขาย Storage สามารถแจ้งว่า:

**ไม่รวม SSD**

ตั้งแต่ต้น

การประเมินจะอิง Configuration ที่ขายจริง

เพื่อถามราคาไม่จำเป็นต้องให้ Password หรือข้อมูลภายใน SSD

---

## หน้าจอควรตรวจตอนเปิดใช้งาน

ควรแจ้งหากมี:

- เส้น
- จุด
- จอแตก
- กระพริบ
- สีเพี้ยน
- แสงผิดปกติ
- ไม่มีภาพ

หากต่อจอนอกแล้วใช้งานได้ สามารถแจ้งข้อมูลนี้ประกอบโดยไม่ต้องสรุปสาเหตุเอง

---

## Keyboard และ Port มีผลต่อความพร้อมใช้งาน

ควรแจ้งหาก:

- ปุ่มเสีย
- Keyboard บางปุ่มกดไม่ติด
- Touchpad มีปัญหา
- USB เสีย
- HDMI มีปัญหา
- Port ชาร์จหลวม
- Speaker มีเสียงผิดปกติ

ข้อมูลเหล่านี้ช่วยอธิบายสภาพของเครื่องได้ครบขึ้น

---

## เครื่องเปิดไม่ติดไม่จำเป็นต้องรีบซ่อม

สามารถเริ่มจากเช็กราคาตามสภาพก่อน

ส่ง:

- Model
- สเปกที่ทราบ
- Adapter
- รูป
- ไฟสถานะ
- อาการก่อนเสีย
- ประวัติซ่อม

จากนั้นจึงค่อยเปรียบเทียบว่าค่าใช้จ่ายในการซ่อมเหมาะสมหรือไม่

หาก Battery บวม มีกลิ่นไหม้ หรือเครื่องร้อนผิดปกติ ไม่ควรทดลองเปิดซ้ำหลายครั้ง

## Notebook หลายเครื่องควรแยกเป็นกลุ่ม

หากมีหลายเครื่องจากสำนักงานหรือองค์กร สามารถจัดข้อมูลเช่น:

| รุ่น | CPU | RAM | SSD | จำนวน | สภาพ |
|---|---|---|---|---|---|
| รุ่น... | i5-... | 8GB | 256GB | 5 | ปกติ |
| รุ่น... | i5-... | 16GB | 512GB | 4 | Battery เสื่อม |
| รุ่น... | ไม่ทราบ | ไม่ทราบ | ไม่ทราบ | 2 | ไม่ได้ทดสอบ |

หากสภาพหรือ Configuration ต่างกัน ควรแยกกลุ่มให้ชัด

## คำถามที่พบบ่อยเกี่ยวกับการขาย Notebook ในกาฬสินธุ์

### Notebook รุ่นเก่ายังเช็กราคาได้ไหม?

ได้ ควรแจ้ง Model สเปก Battery และสภาพปัจจุบันเพื่อประเมินก่อนว่าควรขายตามสภาพหรือซ่อม

### เปลี่ยน SSD หรือเพิ่ม RAM มาแล้วต้องแจ้งไหม?

ควรแจ้ง Configuration ปัจจุบัน เพราะราคาควรอิง Hardware ที่รวมขายจริง

### Battery ไม่เก็บไฟยังประเมินได้ไหม?

ได้ ควรแจ้งอาการและ Adapter ที่ใช้ และไม่จำเป็นต้องเปลี่ยน Battery ก่อนทราบว่าคุ้มกับมูลค่าที่เพิ่มหรือไม่

### เครื่องเปิดไม่ติดต้องซ่อมก่อนขายไหม?

ไม่จำเป็นทุกกรณี สามารถเช็กราคาตามสภาพก่อนแล้วเปรียบเทียบกับต้นทุนและความเสี่ยงในการซ่อม

### ขายโดยเก็บ SSD ไว้ได้หรือไม่?

สามารถแจ้งว่าไม่รวม SSD ได้ ราคาจะประเมินจาก Configuration ที่ขายจริง
