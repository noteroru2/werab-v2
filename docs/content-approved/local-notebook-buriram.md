ผู้ขายที่อยู่ในพื้นที่ เช่น

## Model เต็มสำคัญกว่าชื่อ Series

Notebook ชื่อใกล้กันอาจใช้:

- CPU คนละ Generation
- GPU คนละรุ่น
- RAM ต่างกัน
- SSD ต่างกัน
- Panel ต่างกัน

ดังนั้นควรหา Model เต็มจากใต้เครื่อง BIOS หรือข้อมูลระบบ

หากอ่านไม่ออกสามารถส่งรูปป้าย Model ได้

---

## Gaming Notebook ควรแจ้ง GPU ให้ชัด

Gaming Notebook ใน Series เดียวกันอาจมีตั้งแต่ GPU ระดับเริ่มต้นจนถึงรุ่นสูง

ควรแจ้งเช่น:

**RTX 3050**  
**RTX 3060**  
**RTX 4060**

หรือรุ่นที่ติดตั้งจริง

ไม่ควรใช้คำว่า “Notebook Gaming” เพียงอย่างเดียวในการประเมิน

---

## Battery ควรดูจากการใช้งานจริง

- Battery ยังใช้งานได้

- บวม
- เคยเปลี่ยน

สามารถส่งข้อมูลมาประเมินตามสภาพได้

## เครื่องเคยเพิ่ม RAM หรือ SSD ควรใช้สเปกปัจจุบัน

หากเดิมเครื่องมี RAM 8GB แต่ปัจจุบันเป็น 16GB ให้แจ้ง 16GB

หาก SSD เดิมถูกเปลี่ยนเป็นรุ่นอื่นให้แจ้งของที่อยู่ในเครื่องจริง

ราคาต้องพิจารณาจาก Configuration ที่ขาย

## เครื่องมีข้อมูลส่วนตัวควรจัดการก่อนส่งมอบ

เพื่อขอราคาประเมินไม่จำเป็นต้องให้:

- Password
- PIN
- OTP
- Email Password
- Recovery Key

ผู้ขายควรสำรองข้อมูลและจัดการบัญชีของตนเองก่อนส่งมอบจริง

หากต้องการเก็บ SSD สามารถแจ้งว่าไม่รวม Storage ตั้งแต่ตอนประเมิน

## คำถามที่พบบ่อยเกี่ยวกับการขายโน๊ตบุ๊คมือสองในบุรีรัมย์

### อยู่ต่างอำเภอในบุรีรัมย์เช็กราคาก่อนได้ไหม?

สามารถเริ่มจากส่ง Model สเปก รูป Battery และสภาพก่อน แล้วจึงค่อยพิจารณาวิธีตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

### Gaming Notebook ต้องแจ้ง GPU ไหม?

ควรแจ้งรุ่น GPU เต็ม เพราะ Notebook Series เดียวกันอาจมีหลาย Configuration และ GPU มีผลต่อการแยกรุ่นและมูลค่าของเครื่อง

### จอแตกหรือบานพับเสียยังประเมินได้ไหม?

สามารถส่งข้อมูลมาประเมินตามสภาพได้ ควรถ่ายตำหนิให้เห็นชัดและแจ้งว่าเครื่องยังเปิดใช้งานหรือสามารถต่อจอนอกได้หรือไม่

### Battery เสื่อมควรเปลี่ยนก่อนขายไหม?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพก่อน แล้วเปรียบเทียบค่า Battery กับมูลค่าที่คาดว่าจะเพิ่มหลังเปลี่ยน

### ไม่มี Adapter ขายได้ไหม?

สามารถส่งมาประเมินได้ โดยควรแจ้งว่าไม่มี Adapter ตั้งแต่ต้น ไม่จำเป็นต้องรีบซื้อใหม่ก่อนรู้ว่าคุ้มกับมูลค่าที่เพิ่มหรือไม่
