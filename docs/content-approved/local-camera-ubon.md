## Mount มีความสำคัญเมื่อประเมินกล้องพร้อมเลนส์

หากทราบควรแจ้ง Mount หรือระบบ Lens ที่ใช้

เพราะเลนส์ที่ชื่อหรือระยะใกล้กันอาจเป็นคนละ Mount และใช้กับ Body ต่างระบบ

หากไม่แน่ใจ ไม่จำเป็นต้องคาดเดา สามารถส่งรูปหน้าและท้าย Lens ประกอบได้

## Sensor มีฝุ่นไม่เหมือน Sensor เสีย

หากภาพมีจุด อาจเกิดจากหลายสาเหตุ เช่น:

- ฝุ่นที่ Sensor
- ฝุ่นหรือคราบบน Lens
- สิ่งสกปรกในระบบ Optical
- ปัญหาอื่น

ไม่ควรขัด Sensor ด้วยแรงหรือใช้สารที่ไม่เหมาะสมเพียงเพื่อเตรียมขาย

หากไม่แน่ใจสามารถแจ้งอาการและส่งภาพตัวอย่างแทน

## คำถามที่พบบ่อยเกี่ยวกับการขายกล้องในอุบลราชธานี

### รับเฉพาะ Canon หรือ Nikon ตามชื่อ URL หรือไม่?

ไม่ใช่ ชื่อ URL เป็น Historical Path เดิม ส่วนหน้านี้รักษา Intent กล้องมือสองในอุบลราชธานี และชื่อแบรนด์ใช้เพื่อจำแนกสินค้าเท่านั้น

### Shutter Count สูงยังเช็กราคาได้ไหม?

ได้ ควรดูร่วมกับ Body Sensor AF จอ EVF Lens และประวัติซ่อม ไม่ควรใช้ Shutter Count เพียงอย่างเดียว

### กล้องมีจุดในภาพต้องทำความสะอาด Sensor ก่อนหรือไม่?

ไม่จำเป็นทุกกรณี ควรตรวจว่าอาการอาจมาจาก Sensor หรือ Lens ก่อน และไม่ควรใช้วิธีทำความสะอาดที่เสี่ยงเพียงเพื่อเตรียมขาย

### Auto Focus มีอาการยังประเมินได้ไหม?

ได้ ควรแจ้งอาการและ Lens ที่ใช้ทดสอบ เพื่อให้เข้าใจว่าปัญหาอาจเกี่ยวข้องกับ Body หรือ Lens

### ไม่มีกล่องหรือ Charger ยังส่งมาประเมินได้หรือไม่?

ได้ ควรแจ้งอุปกรณ์ที่มีจริง ไม่จำเป็นต้องซื้อของใหม่มาเติมชุดก่อนเช็กราคา
