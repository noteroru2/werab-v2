# รับซื้อสินค้าไอทีมือสอง เช็กราคาก่อนขายก่อนตัดสินใจ


ตรวจข้อมูลสินค้า รุ่น สเปก สภาพ และรายละเอียดที่มี


หากข้อมูลไม่พอ อาจต้องขอรูปหรือข้อมูลเพิ่มเติม


### พิจารณาราคาและเงื่อนไข


หลังทราบข้อมูลเบื้องต้น ผู้ขายสามารถพิจารณาได้ว่าต้องการขายหรือเก็บสินค้าไว้ก่อน


การส่งข้อมูลมาประเมินไม่ได้หมายความว่าต้องตกลงขายทันที


### ตกลงวิธีส่งหรือนัดหมาย


เมื่อตัดสินใจขายแล้วจึงตกลงวิธีนำส่งสินค้า หรือนัดหมายตามประเภทสินค้า พื้นที่ และคิวงาน


### ตรวจสินค้าจริง


ตรวจรุ่น สเปก สภาพ การทำงาน และอุปกรณ์ว่าตรงกับข้อมูลที่ใช้ประเมินหรือไม่


### ซื้อขายและชำระเงิน


เมื่อรายละเอียดตรงตามที่ตกลง จึงดำเนินการซื้อขายตามเงื่อนไขที่ตกลงกัน


[ดูขั้นตอนการขาย](/วิธีขาย/)

## ทำไมควรเช็กราคาก่อนซ่อมหรือซื้ออุปกรณ์เพิ่ม


หลายคนเตรียมขายสินค้าด้วยการซื้อกล่อง ที่ชาร์จ เปลี่ยนแบตเตอรี่ หรือส่งซ่อมก่อน


แต่ค่าใช้จ่ายที่เพิ่มขึ้นไม่ได้หมายความว่าราคาขายจะเพิ่มขึ้นเท่ากันทุกกรณี


ก่อนจ่ายค่าซ่อมหรือซื้ออุปกรณ์เพิ่ม ควรเปรียบเทียบก่อนว่า


- ราคาตามสภาพปัจจุบันประมาณไหน
- ค่าซ่อมเท่าไร
- หลังซ่อมมูลค่าเพิ่มประมาณไหน
- ความเสี่ยงของการซ่อมมีอะไร
- ต้องใช้เวลาเพิ่มหรือไม่


การรู้ข้อมูลเหล่านี้ช่วยให้ตัดสินใจได้ว่าควรซ่อมก่อนขาย หรือขายตามสภาพเดิม

## ถ้าไม่รู้รุ่นหรือสเปก ทำอย่างไร


ไม่เป็นไร


สามารถเริ่มจากส่งรูปตัวเครื่องและป้ายรุ่นมาได้


สำหรับ Notebook หรือคอมพิวเตอร์อาจส่งรูปหน้า System Information, Task Manager หรือข้อมูลสเปกที่มี


สำหรับ iPhone และ iPad สามารถส่งข้อมูลจากหน้า About


สำหรับกล้องและลำโพงมักมี Model Number อยู่ใต้เครื่อง ด้านหลัง หรือบริเวณช่องแบตเตอรี่


เป้าหมายคือให้ระบุสินค้าได้ถูกต้องก่อนเริ่มประเมิน
