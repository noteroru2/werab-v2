## ชุมแพเป็น Historical Intent ระดับพื้นที่ย่อย

ผู้ค้นหาที่ระบุคำว่า **ชุมแพ** มี Location Intent แคบกว่าคำว่า **ขอนแก่น**

โครงสร้างจึงควรเป็น:

**Notebook หลัก → ขอนแก่นระดับจังหวัด → ชุมแพ**

ไม่ใช่ให้หน้าอำเภอแข่งขันโดยตรงกับ Parent Money Hub

การมีหน้าเฉพาะชุมแพไม่ได้หมายความว่ามีสาขา พนักงาน หรือจุดรับซื้อประจำอยู่ในพื้นที่

## เครื่องมีอาการสามารถเช็กข้อมูลก่อนตัดสินใจซ่อมได้

หาก Notebook มีปัญหา เช่น

- เปิดช้า
- จอฟ้า
- ดับ
- Battery เสื่อม
- Keyboard เสีย
- จอมีปัญหา
- บานพับแตก

ควรเริ่มจากตรวจ Model และสเปกก่อน

เครื่องรุ่นต่างกันอาจมีความคุ้มค่าในการซ่อมต่างกัน แม้อาการภายนอกเหมือนกัน

---

## Model และ Configuration ต้องตรงกับเครื่องปัจจุบัน

Notebook ที่ผ่านการใช้งานอาจถูก:

- เพิ่ม RAM
- เปลี่ยน SSD
- เปลี่ยน Battery
- เปลี่ยนจอ

ดังนั้นควรแจ้งสิ่งที่อยู่ในเครื่องจริงในปัจจุบัน

ไม่ควรใช้สเปกจากหน้าสินค้าเดิมโดยไม่ตรวจเครื่อง

---

## CPU และ GPU ช่วยแยกมูลค่าเครื่อง

ควรแจ้ง CPU แบบเต็ม เช่น:

**Core i5-12500H**

หรือ:

**Ryzen 7 6800H**

หากเป็น Gaming Notebook ควรแจ้ง GPU ด้วย

เช่น:

**RTX 3050**

**RTX 3060**

**RTX 4060 Laptop GPU**

ชื่อ Series ของเครื่องเพียงอย่างเดียวอาจไม่พอ

---

## เครื่องเล่นเกมดับหรือร้อนควรแจ้งตามอาการ

หากมีอาการเวลาใช้งานหนัก เช่น

- ดับ
- Restart
- ภาพแตก
- GPU Error
- จอฟ้า
- Fan ดัง
- Temperature สูงผิดปกติ

ควรแจ้งตามที่พบ

ไม่จำเป็นต้อง Stress Test ซ้ำอย่างหนักเพียงเพื่อถามราคา โดยเฉพาะเมื่อเครื่องไม่เสถียรอยู่แล้ว

---

## Battery กับระบบชาร์จควรแยกข้อมูล

ควรแจ้งว่า:

- Battery หมดเร็ว
- Battery ไม่เก็บไฟ
- Battery บวม
- ชาร์จไม่เข้า
- Port ชาร์จหลวม
- Adapter มีปัญหา

อาการเหล่านี้ไม่ควรถูกสรุปว่าเกิดจากอะไหล่ตัวใดโดยไม่มีการตรวจ

---

## หน้าจอและบานพับควรถ่ายชัดเจน

หากมีจอ:

- แตก
- เป็นเส้น
- กระพริบ
- มีจุด
- สีผิดปกติ

ควรถ่ายขณะเปิดเครื่อง

หากบานพับมีปัญหา ควรถ่ายทั้งสองข้างและบริเวณฝาจอหรือ Palmrest ที่เกี่ยวข้อง

---

## ไม่มี Adapter ยังส่งมาประเมินได้

ควรแจ้งว่า:

**ไม่มี Adapter**

หรือ:

**ใช้ Adapter เทียบ**

ไม่จำเป็นต้องซื้อใหม่ก่อนทราบว่าต้นทุนคุ้มกับมูลค่าที่อาจเพิ่มขึ้นหรือไม่

---

## เครื่องเปิดไม่ติดควรหยุดทดสอบเมื่อมีอาการเสี่ยง

สามารถสังเกตไฟสถานะ Fan หรืออาการพื้นฐานได้

แต่ถ้ามี:

- กลิ่นไหม้
- ความร้อนผิดปกติ
- Battery บวม
- ร่องรอยของเหลว

ไม่ควรเปิดหรือชาร์จซ้ำหลายครั้ง

สามารถส่งข้อมูลตามสภาพเพื่อประเมินเบื้องต้นได้

---

## ประวัติซ่อมช่วยอธิบายสภาพของเครื่อง

ควรแจ้งถ้าทราบว่าเคย:

- ซ่อม Mainboard
- เปลี่ยนจอ
- เปลี่ยน Battery
- เปลี่ยน Keyboard
- ซ่อมบานพับ
- เปลี่ยน SSD
- เพิ่ม RAM
- โดนน้ำ

ไม่จำเป็นต้องมีเอกสารทุกครั้ง แต่ควรแจ้งข้อมูลที่ทราบตามจริง

---

## ไม่ต้องให้รหัสผ่านเพื่อเช็กราคา

ไม่ควรส่ง:

- Password
- PIN
- OTP
- Recovery Key
- Email Password

การประเมิน Hardware เบื้องต้นไม่จำเป็นต้องใช้ข้อมูลลับของเจ้าของเครื่อง

## คำถามที่พบบ่อยเกี่ยวกับการขาย Notebook ในชุมแพ

### หน้าชุมแพต่างจากหน้ารับซื้อโน๊ตบุ๊คขอนแก่นอย่างไร?

หน้าขอนแก่นเป็นเจ้าของ Intent ระดับจังหวัด ส่วนหน้านี้รักษา Historical Search Intent ที่เจาะจงชุมแพ จึงอยู่ในลำดับชั้นพื้นที่ที่แคบกว่า

### Gaming Notebook มีอาการดับยังเช็กราคาได้ไหม?

ได้ ควรแจ้ง Model CPU GPU อาการและประวัติซ่อมตามจริง และไม่จำเป็นต้อง Stress Test หนักซ้ำหากเครื่องไม่เสถียร

### จอแตกหรือบานพับเสียต้องซ่อมก่อนขายหรือไม่?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพก่อน แล้วเปรียบเทียบค่าอะไหล่ ค่าแรงและมูลค่าที่คาดว่าจะเพิ่ม

### ไม่มี Adapter ยังขายได้ไหม?

สามารถส่งมาประเมินได้ โดยควรแจ้งว่าไม่มี Adapter ตั้งแต่ต้น

### เครื่องเปิดไม่ติดควรทดลองเปิดหลายครั้งไหม?

ไม่ควรทดลองซ้ำหลายครั้งหากมี Battery บวม กลิ่นไหม้ ความร้อนผิดปกติ หรือร่องรอยของเหลว
