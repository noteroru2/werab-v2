## Battery Health ควรส่งค่าที่ระบบแสดง

หาก iPhone ยังแสดง Battery Health สามารถส่งเปอร์เซ็นต์นั้นประกอบได้

ควรแจ้งด้วยหาก:

- เคยเปลี่ยน Battery
- มีข้อความเกี่ยวกับชิ้นส่วน
- Battery หมดเร็ว
- เครื่องดับ
- ชาร์จผิดปกติ
- Battery บวม

หาก Battery บวม ไม่ควรกดตัวเครื่องหรือชาร์จซ้ำโดยไม่จำเป็น

## ประวัติการเปลี่ยนอะไหล่ควรแจ้งตามที่ทราบ

ควรแจ้งหากเครื่องเคย:

- เปลี่ยนจอ
- เปลี่ยน Battery
- เปลี่ยนฝาหลัง
- เปลี่ยนกล้อง
- ซ่อมระบบชาร์จ
- ซ่อม Board
- โดนน้ำ
- ตกกระแทกหนัก

ประวัติซ่อมไม่ได้หมายความว่าเครื่องขายไม่ได้ แต่ช่วยให้สภาพที่ใช้ประเมินตรงกับเครื่องจริงมากขึ้น

- เส้น
- สีผิดปกติ
- Touch ไม่ครบ
- จอกระพริบ
- แสงผิดปกติ

- ระบบแสดงข้อความผิดปกติ

หากใช้ไม่ได้ ไม่ควรวินิจฉัยสาเหตุเองว่าเกิดจากชิ้นส่วนใดโดยไม่มีการตรวจ

- ปุ่มมีปัญหา

## Apple ID และ Find My ต้องจัดการโดยเจ้าของเครื่อง

ก่อนส่งมอบจริง เจ้าของควรสามารถจัดการบัญชีที่ผูกกับเครื่องของตนเองได้

แต่เพื่อสอบถามราคา **ไม่ต้องส่งรหัสลับ**

ไม่ควรส่ง:

- Apple ID Password
- Passcode
- PIN
- OTP
- Recovery Key
- Email Password

การประเมินเบื้องต้นไม่จำเป็นต้องได้รับข้อมูลเหล่านี้

ไม่จำเป็นต้องซื้ออุปกรณ์ใหม่มาเติมชุดก่อนทราบว่าคุ้มกับมูลค่าที่เพิ่มหรือไม่

## คำถามที่พบบ่อยเกี่ยวกับการขาย iPhone ในร้อยเอ็ด

### Battery Health ต่ำยังเช็กราคาได้ไหม?

ได้ ควรแจ้งเปอร์เซ็นต์ตามที่ระบบแสดงและประวัติเปลี่ยน Battery ถ้าทราบ ไม่จำเป็นต้องเปลี่ยนก่อนสอบถามราคา

### iPhone เปลี่ยนจอมาแล้วประเมินได้หรือไม่?

สามารถส่งมาประเมินตามสภาพได้ ควรแจ้งประวัติที่ทราบและสภาพหน้าจอ Touch และฟังก์ชันปัจจุบัน

### Face ID ใช้ไม่ได้ยังเช็กราคาได้ไหม?

ได้ ควรแจ้งอาการตามจริง เพราะเป็นส่วนหนึ่งของความพร้อมใช้งานของเครื่อง

### ไม่มีกล่องยังขายได้หรือไม่?

สามารถเช็กราคาได้ โดยแจ้งอุปกรณ์ที่รวมขายจริง ไม่จำเป็นต้องซื้อของใหม่มาเติมชุด

### ต้องให้ Apple ID Password หรือ OTP เพื่อถามราคาไหม?

ไม่ต้อง และไม่ควรส่ง Apple ID Password, Passcode, PIN, OTP หรือ Recovery Key เพื่อขอราคาประเมิน
