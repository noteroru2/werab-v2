## เช็กราคาก่อนตัดสินใจซื้ออุปกรณ์มาเติมชุด

Notebook มือสองบางเครื่องอาจ:

- ไม่มีกล่อง
- ไม่มี Adapter
- Battery เสื่อม
- RAM น้อย
- SSD ความจุน้อย
- มีรอย

ไม่จำเป็นต้องซื้ออุปกรณ์หรืออัปเกรดทุกอย่างก่อนขาย

ควรรู้ราคาตามสภาพปัจจุบันก่อน แล้วค่อยตัดสินใจว่าต้นทุนเพิ่มเติมคุ้มกับมูลค่าที่เพิ่มขึ้นหรือไม่

---

## อยู่ร้อยเอ็ดสามารถเริ่มจากส่งข้อมูลก่อนได้

การสอบถามราคาเบื้องต้นสามารถเริ่มจากข้อมูลและรูปเครื่อง

ไม่จำเป็นต้องเดินทางพร้อม Notebook เพียงเพื่อถามราคา

หลังทราบข้อมูลแล้วจึงค่อยพิจารณาการตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ในทุกพื้นที่ของจังหวัดร้อยเอ็ด

---

## Model เต็มช่วยลดการประเมินผิดรุ่น

Notebook หน้าตาคล้ายกันอาจเป็นคนละ:

- Generation
- CPU
- RAM
- SSD
- GPU
- Display

ควรตรวจ Model จากตัวเครื่องหรือระบบ

หากไม่แน่ใจให้ส่งรูปป้าย Model แทนการคาดเดา

---

## CPU และ GPU ควรระบุแยกกัน

Notebook ทำงานทั่วไปอาจไม่มี Dedicated GPU

Gaming Notebook มักมี GPU เพิ่มเติม

ควรแจ้ง:

**CPU รุ่นเต็ม**

และถ้ามี:

**GPU รุ่นเต็ม**

ช่วยให้แยก Configuration ได้ถูกต้อง

---

## RAM และ SSD ที่เพิ่มมาแล้วควรนับตามของจริง

ตัวอย่าง:

เดิมเครื่องมี:

**RAM 8GB / SSD 256GB**

แต่ปัจจุบันเป็น:

**RAM 16GB / SSD 1TB**

ควรใช้ Configuration ปัจจุบันในการประเมิน หาก Hardware เหล่านั้นรวมขายจริง

---

## Adapter มีผลแต่ไม่ควรรีบซื้อใหม่

ควรแจ้ง:

- Adapter เดิม
- Adapter เทียบ
- ไม่มี Adapter
- สายชำรุด
- ชาร์จไม่ปกติ

จากนั้นจึงค่อยพิจารณาว่าการหา Adapter มาเพิ่มคุ้มค่าหรือไม่

---

## Battery ควรแจ้งตามอาการจริง

ตัวอย่าง:

- ใช้งานได้ปกติ
- หมดเร็ว
- ไม่เก็บไฟ
- ต้องเสียบ Adapter
- เคยเปลี่ยน
- Health ต่ำ
- Battery บวม

หาก Battery บวมควรหลีกเลี่ยงการใช้งานหนักและการกดตัวเครื่องบริเวณที่นูน

---

## จอ Keyboard และบานพับควรตรวจพร้อมกัน

Notebook ที่ CPU และสเปกดีอาจยังมีต้นทุนซ่อมจากส่วนอื่น

ควรแจ้งหากมี:

- จอเป็นเส้น
- จอแตก
- จุดดำ
- Keyboard เสีย
- ปุ่มหลุด
- Touchpad เสีย
- บานพับแตก
- ฝาหลังเสียหาย

ควรถ่ายตำหนิให้เห็นก่อนประเมิน

---

## เครื่องเคยโดนน้ำควรแจ้ง

ควรแจ้งว่า:

- โดนน้ำเมื่อไรโดยประมาณ
- บริเวณใด
- หลังจากนั้นยังเปิดได้หรือไม่
- เคยทำความสะอาดหรือซ่อมหรือไม่
- ปัจจุบันมีอาการอะไร

ความเสียหายจากของเหลวอาจมีผลต่อ Hardware มากกว่ารอยภายนอกที่เห็น

- Model

- GPU
- RAM
- SSD

หากมีกลิ่นไหม้ Battery บวม หรือความร้อนผิดปกติ ไม่ควรเปิดหรือชาร์จซ้ำหลายครั้งโดยไม่จำเป็น

## คำถามที่พบบ่อยเกี่ยวกับการขาย Notebook ในร้อยเอ็ด

### ไม่มีกล่องหรือ Adapter ยังเช็กราคาได้ไหม?

ได้ ควรแจ้งอุปกรณ์ที่มีจริง ไม่จำเป็นต้องซื้อของใหม่มาเติมชุดก่อนทราบว่าคุ้มกับมูลค่าที่เพิ่มขึ้นหรือไม่

### Notebook เพิ่ม RAM หรือ SSD มาแล้วมีผลไหม?

ควรแจ้ง Configuration ปัจจุบันและสิ่งที่รวมขายจริง เพราะอาจต่างจากสเปกตอนซื้อใหม่

### เครื่องเคยโดนน้ำยังประเมินได้หรือไม่?

สามารถส่งข้อมูลตามสภาพได้ ควรแจ้งประวัติที่ทราบ อาการปัจจุบัน และไม่ควรปิดบังความเสียหายจากของเหลว

### Battery บวมควรเปิดเครื่องทดสอบไหม?

ไม่ควรใช้งานหนักหรือเปิดทดสอบซ้ำโดยไม่จำเป็น ควรแจ้งสภาพ Battery และรูปประกอบแทน

### เครื่องเปิดไม่ติดต้องซ่อมก่อนขายไหม?

ไม่จำเป็นทุกกรณี สามารถเช็กราคาตามสภาพก่อน แล้วค่อยเปรียบเทียบต้นทุนและความเสี่ยงในการซ่อม
