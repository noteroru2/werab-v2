# รับซื้อคอมขอนแก่น เช็กสเปกและมูลค่า Hardware ก่อนขาย

คอมพิวเตอร์มือสองในขอนแก่นหนึ่งเครื่องอาจมีมูลค่าต่างกันมาก แม้ใช้ Case รุ่นเดียวกัน เพราะ Hardware ภายในสามารถถูกอัปเกรดหรือถอดเปลี่ยนได้ตลอดอายุการใช้งาน

หน้า `/รับซื้อคอม-ขอนแก่น/` จึงเน้นการประเมิน **Desktop, Gaming PC, Workstation และคอมประกอบในพื้นที่ขอนแก่นจาก Configuration ปัจจุบัน**

เริ่มจาก:

## ผู้ขายในขอนแก่นเริ่มประเมินจากรูปและสเปกก่อนได้

หากอยู่ใน:

- อำเภอเมืองขอนแก่น
- ชุมแพ
- บ้านไผ่
- พล
- น้ำพอง
- กระนวน
- หรือพื้นที่อื่นในจังหวัดขอนแก่น

สามารถเริ่มจากข้อมูลเครื่องก่อนโดยไม่จำเป็นต้องขน Case หรือชุดคอมเพื่อถามราคา

หลังประเมินเบื้องต้นจึงค่อยพิจารณาวิธีตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

ไม่ได้หมายความว่ามีหน้าร้านหรือจุดรับซื้ออยู่ทุกอำเภอ

---

## อย่าประเมินคอมประกอบจากราคาตอนซื้อเพียงอย่างเดียว

ราคาตอนประกอบใหม่อาจประกอบด้วย:

- Hardware ที่ปัจจุบันถูกเปลี่ยนออกแล้ว
- ค่า Case
- ค่าไฟ RGB
- ค่าอุปกรณ์ตกแต่ง
- ค่า Windows หรือ Software
- ค่าแรงประกอบ

แต่ราคามือสองต้องดูชิ้นส่วนที่อยู่ในเครื่องจริงในปัจจุบัน

ดังนั้นใบเสร็จเดิมใช้ช่วยตรวจข้อมูลได้ แต่ไม่ใช่ตัวกำหนดราคาปัจจุบันเพียงอย่างเดียว

---

## การ์ดจอและ CPU ควรระบุให้ครบก่อน

สำหรับ Gaming PC ควรเริ่มจากสองรายการนี้

ตัวอย่าง:

**CPU: Intel Core i5-13400F**  
**GPU: RTX 4060 8GB**

หรือ

**CPU: Ryzen 7 5700X**  
**GPU: RX 6700 XT**

ไม่ควรใช้คำว่า “i5 + RTX” เพราะยังไม่สามารถแยก Generation และระดับ Hardware ได้ชัดเจน

---

## Mainboard สำคัญเมื่อเครื่องมีการอัปเกรด

ผู้ขายบางรายทราบ CPU และ GPU แต่ไม่ทราบ Board

หากทำได้ควรแจ้ง:

- Brand
- Model
- Chipset

เพราะ Board สามารถมีผลต่อ:

- Platform
- RAM Generation
- Expansion
- Storage
- Upgrade Path

หากไม่ทราบสามารถถ่ายรูปภายใน Case ให้เห็นชื่อรุ่นบน Board ได้

---

## RAM ต้องดูทั้งความจุและ Generation

ควรแจ้ง:

- DDR4 หรือ DDR5
- ความจุรวม
- จำนวนแถว
- ความเร็วถ้าทราบ

เช่น

**DDR5 16GB × 2 = 32GB**

เครื่องที่ระบุเพียงว่า “RAM เยอะ” ยังไม่เพียงพอต่อการแยก Configuration

---

## SSD หลายลูกต้องแจ้งสิ่งที่ขายจริง

ตัวอย่าง:

เครื่องมี:

- NVMe 1TB
- SATA SSD 500GB
- HDD 2TB

แต่ผู้ขายต้องการเก็บ NVMe 1TB ไว้

ควรแจ้งตั้งแต่ตอนประเมินว่า Storage ใดรวมขายจริง

ไม่ควรใช้สเปกเต็มของเครื่องแล้วถอด Drive ออกภายหลังโดยไม่แจ้ง

---

## Workstation ควรแยกจาก Gaming PC อย่างไร

Workstation บางเครื่องใช้ Hardware ที่ต่างจาก Gaming PC เช่น

- CPU รุ่นที่มี Core สูง
- RAM ปริมาณมาก
- Professional GPU
- Storage หลายลูก
- Expansion Card
- Hardware เฉพาะงาน

หากเป็น Workstation ควรแจ้ง Configuration เต็มเท่าที่ทราบ ไม่ควรประเมินจากรูปลักษณ์ Case หรือ GPU เพียงชิ้นเดียว

---

## เครื่องขายพร้อม Monitor ควรแยกรายการ

Monitor มีมูลค่าของตัวเอง

ควรแจ้ง:

- Brand
- Model
- Size
- Resolution
- Refresh Rate
- Panel condition

แล้วระบุว่า:

**ขายพร้อมคอม**

หรือ

**จอไม่รวมขาย**

ช่วยป้องกันความคลาดเคลื่อนเมื่อตรวจสินค้าจริง

---

## เครื่องไม่มีการ์ดจอยังประเมินได้ไหม

ได้

บางเครื่องใช้ Integrated Graphics หรือขายหลังจากถอด GPU ออกแล้ว

ควรแจ้งว่า:

**ไม่รวมการ์ดจอ**

และแจ้ง CPU ให้ชัด เพราะ CPU บางรุ่นมี iGPU และบางรุ่นไม่มี

ไม่ควรสมมติว่าเครื่องเปิดใช้งานได้โดยไม่ตรวจว่า Configuration ปัจจุบันรองรับภาพออกหรือไม่

---

## PSU ไม่ควรถูกมองข้าม

ควรถ่าย Label ของ PSU หากอ่านรุ่นได้

ข้อมูลสำคัญ:

- Brand
- Model
- Watt
- Rating
- Modular หรือไม่ถ้าทราบ
- สภาพสาย
- อาการ

PSU ที่ไม่มีข้อมูลชัดกับ PSU รุ่นที่ตรวจสอบได้ไม่ควรถูกประเมินเหมือนกันโดยอัตโนมัติ

---

## คอมมีอาการแต่ยังเปิดได้ต้องแจ้งตามจริง

ตัวอย่าง:

- Boot ช้า
- Windows ค้าง
- จอฟ้า
- Restart
- ดับระหว่างเล่นเกม
- GPU มี Artifact
- SSD มี Error
- พัดลมดัง
- Temperature สูง
- USB บาง Port เสีย

อาการเหล่านี้มีผลต่อความเสี่ยงในการตรวจ

ไม่ควรซ่อนอาการเพื่อให้เครื่องดูเหมือนปกติ

---

## เครื่องเปิดไม่ติดควรใช้หน้าคอมนี้หรือซากคอม

หากเครื่องเปิดไม่ติดแต่ยังมี Configuration ชัด สามารถส่งข้อมูลเบื้องต้นได้

แต่หาก:

- เสียหนัก
- ถอดชิ้นส่วนหลายรายการ
- ไม่สามารถทดสอบ Hardware
- เหลือเป็นอะไหล่

Intent จะใกล้กับ **รับซื้อซากคอมพิวเตอร์** มากกว่า

หน้า `/รับซื้อคอม-ขอนแก่น/` จึงรักษา Local Intent ของเครื่อง Desktop/PC เป็นหลัก ไม่ใช่หน้าซากคอมประจำจังหวัด

---

## บริษัทหรือสำนักงานในขอนแก่นมีหลายเครื่องควรจัดกลุ่ม

ควรแยกตาม Configuration เช่น

| กลุ่ม | CPU | RAM | Storage | จำนวน | สถานะ |
|---|---|---|---|---|---|
| A | i5-... | 16GB | 512GB | 6 | ใช้งานได้ |
| B | i5-... | 8GB | 256GB | 10 | มีรอย |
| C | ไม่ทราบ | ไม่ทราบ | ไม่มี | 3 | ยังไม่ได้ทดสอบ |

หากมี Asset Tag สามารถใช้จัดรายการภายในได้ แต่ไม่จำเป็นต้องส่งข้อมูลบริษัทอื่นที่ไม่เกี่ยวกับ Hardware

## คำถามที่พบบ่อยเกี่ยวกับการขายคอมมือสองในขอนแก่น

### คอมประกอบในขอนแก่นต้องแจ้งอะไรเพื่อเช็กราคา?

ควรแจ้ง CPU, GPU, RAM, SSD, Mainboard, PSU และรูปภายใน Case เพราะคอมประกอบรุ่นเดียวกันภายนอกอาจมี Hardware ภายในต่างกันมาก

### ถอดการ์ดจอเก็บไว้แล้วขายเครื่องที่เหลือได้ไหม?

สามารถแจ้งว่าไม่รวม GPU ได้ ราคาจะประเมินจาก Configuration ที่ขายจริง และควรแจ้งตั้งแต่ต้นว่า GPU ถูกถอดออกแล้ว

### Workstation ขายเหมือน Gaming PC ไหม?

ควรแจ้งสเปกเต็มของ Workstation เพราะ CPU, RAM, GPU และ Expansion อาจต่างจาก Gaming PC ทั่วไป จึงไม่ควรใช้เพียงรูปลักษณ์ Case เป็นฐานประเมิน

### คอมเปิดไม่ติดยังส่งข้อมูลได้ไหม?

สามารถส่งข้อมูลเบื้องต้นได้ แต่ถ้าเสียหนักหรือไม่สามารถทดสอบ Hardware หลายส่วน Intent อาจเข้ากับการประเมินซากคอมพิวเตอร์มากกว่า

### มีคอมหลายเครื่องในขอนแก่นควรส่งรูปทุกเครื่องไหม?

ควรเริ่มจากแยก Model หรือ Configuration เป็นกลุ่ม พร้อมจำนวนและสภาพ หากเครื่องในกลุ่มเดียวกันเหมือนกันสามารถจัดข้อมูลร่วมกันได้และค่อยส่งรูปตัวอย่างกับจุดที่ต่างกัน
