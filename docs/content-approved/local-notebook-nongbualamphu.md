## เริ่มจากเช็กราคาก่อนวางแผนเดินทางหรือส่งมอบ

สำหรับ Notebook มือสอง สิ่งที่มีผลต่อการประเมินไม่ได้มีเพียงอายุเครื่อง

Notebook ที่ซื้อในช่วงเวลาใกล้กันอาจมี:

- CPU คนละ Generation
- RAM ต่างกัน
- SSD ต่างความจุ
- GPU ต่างรุ่น
- Battery ต่างสภาพ
- อุปกรณ์ไม่เท่ากัน

ผู้ขายในหนองบัวลำภูจึงสามารถเริ่มจากส่งข้อมูลและรูปเครื่องก่อน แล้วค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามพื้นที่และความเหมาะสม

หน้า Local นี้ไม่ได้หมายความว่ามีสาขาหรือจุดรับซื้อประจำอยู่ทุกพื้นที่ของจังหวัดหนองบัวลำภู

## รุ่นเต็มช่วยป้องกันการประเมินผิดเครื่อง

คำว่า:

**Acer Aspire**

**ASUS VivoBook**

**Lenovo IdeaPad**

**HP Pavilion**

อาจเป็นชื่อ Series ที่มีหลายรุ่นย่อย

- ป้ายใต้เครื่อง
- BIOS
- System Information
- About
- โปรแกรมของผู้ผลิต
- กล่องเดิม

หากอ่านไม่ออก สามารถถ่ายรูปป้ายใต้เครื่องมาใช้ประกอบการแยกรุ่นได้

ตัวอย่าง:

**Intel Core i5-8250U**

กับ

**Intel Core i5-1235U**

แม้เป็น Core i5 เหมือนกัน แต่เป็นคนละ Generation

เช่นเดียวกับ:

กับ

**Ryzen 5 7530U**

การแจ้งรหัสเต็มช่วยให้เข้าใจ Platform ของเครื่องได้ตรงกว่า

## Notebook ที่เคยอัปเกรดต้องแจ้งสเปกปัจจุบัน

หากซื้อเครื่องมาเดิมเป็น:

**RAM 8GB / SSD 256GB**

แต่ปัจจุบันอัปเกรดเป็น:

**RAM 16GB / SSD 1TB**

ควรแจ้ง Configuration ปัจจุบัน หาก Hardware เหล่านั้นรวมขายจริง

หากต้องการถอด SSD หรือ RAM บางส่วนเก็บไว้ ควรแจ้งตั้งแต่ก่อนประเมินเพื่อให้ใช้ Configuration ที่ถูกต้อง

---

## Gaming Notebook ต้องรู้ GPU และ Adapter

สำหรับ Gaming Notebook การแจ้งเพียงชื่อ Series อาจยังไม่พอ

ควรส่ง:

- CPU
- GPU
- RAM
- SSD
- Adapter
- สภาพจอ

ตัวอย่าง GPU:

- GTX Series
- RTX Series
- Radeon รุ่นที่ติดตั้งในเครื่อง

ควรระบุรุ่นเต็มเท่าที่ตรวจได้ เพราะ Gaming Notebook รุ่นเดียวกันอาจมี GPU หลาย Configuration

---

## Battery ควรแจ้งทั้ง Health และอาการใช้งาน

ถ้าเครื่องมีข้อมูล Battery Health สามารถส่งประกอบได้

หากไม่มี ให้แจ้งจากการใช้งานจริง เช่น:

- ใช้งานได้ตามปกติ
- หมดเร็ว
- ไม่เก็บไฟ
- ต้องเสียบ Adapter
- ชาร์จไม่เต็ม
- เคยเปลี่ยน Battery
- Battery บวม

หาก Battery บวม ไม่ควรกดตัวเครื่องบริเวณที่นูนหรือใช้งานหนักโดยไม่จำเป็น

---

## Adapter เดิม Adapter เทียบ หรือไม่มี Adapter ควรแจ้ง

Notebook บางรุ่นต้องใช้ Adapter ที่มีกำลังไฟเฉพาะ

ควรแจ้งว่า:

- Adapter เดิม
- Adapter เทียบ
- มีเฉพาะสาย
- ไม่มี Adapter
- Adapter มีอาการ

ไม่จำเป็นต้องซื้อ Adapter ใหม่ก่อนรู้ว่าต้นทุนที่เพิ่มขึ้นคุ้มกับมูลค่าเครื่องหรือไม่

## คำถามที่พบบ่อยเกี่ยวกับการขาย Notebook ในหนองบัวลำภู

### อยู่หนองบัวลำภูสามารถส่งรูปเช็กราคาก่อนได้ไหม?

สามารถเริ่มจากส่ง Model สเปก Battery รูป สภาพและอุปกรณ์ก่อน แล้วจึงค่อยพิจารณาขั้นตอนตรวจสินค้าและส่งมอบตามความเหมาะสม

### Notebook เพิ่ม RAM หรือ SSD มาแล้วควรแจ้งแบบไหน?

ควรแจ้ง Configuration ปัจจุบันและ Hardware ที่รวมขายจริง ไม่จำเป็นต้องยึดตามสเปกเดิมตอนซื้อเครื่อง

### Battery เสื่อมต้องเปลี่ยนก่อนขายไหม?

ไม่จำเป็นทุกกรณี ควรเช็กราคาตามสภาพก่อนแล้วเปรียบเทียบต้นทุนเปลี่ยน Battery กับมูลค่าที่อาจเพิ่ม

### เครื่องเปิดไม่ติดยังเช็กราคาได้ไหม?

ได้ สามารถส่ง Model สเปกที่ทราบ รูป Adapter อาการและประวัติซ่อมเพื่อประเมินเบื้องต้นก่อน

### ไม่มี Adapter ยังประเมินได้หรือไม่?

ได้ ควรแจ้งว่าไม่มี Adapter ตั้งแต่ต้น ไม่จำเป็นต้องซื้อใหม่ก่อนรู้ว่าคุ้มกับมูลค่าที่เพิ่มขึ้นหรือไม่
