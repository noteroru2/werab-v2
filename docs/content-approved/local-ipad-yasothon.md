## คำถามที่พบบ่อยเกี่ยวกับการขาย iPad ในยโสธร

### iPad Air, mini และ Pro ต้องแจ้ง Generation หรือไม่?

ควรแจ้ง Generation ชิปหรือ Model เท่าที่ตรวจได้ เพราะชื่อรุ่นแต่ละตระกูลมีหลาย Generation และ Configuration

### Battery เสื่อมต้องเปลี่ยนก่อนขายไหม?

ไม่จำเป็นทุกกรณี สามารถแจ้งข้อมูล Battery หรืออาการใช้งานแล้วเช็กราคาตามสภาพก่อนตัดสินใจเปลี่ยน

### Cellular iPad ต้องส่ง IMEI เพื่อถามราคาไหม?

ไม่จำเป็นสำหรับการสอบถามราคาเบื้องต้น เริ่มจากรุ่น ความจุ Wi-Fi/Cellular รูปและสภาพก่อน และไม่ควรโพสต์ IMEI สาธารณะโดยไม่จำเป็น

### Apple Pencil หรือ Keyboard มีผลไหม?

ควรแจ้งรุ่นและอุปกรณ์ที่รวมขายจริง เพราะ Pencil และ Keyboard มีหลาย Generation และรองรับ iPad ต่างรุ่นกัน

### ต้องส่ง Apple ID Password หรือ OTP เพื่อเช็กราคาไหม?

ไม่ต้อง และไม่ควรส่ง Apple ID Password, Passcode, PIN, OTP หรือ Recovery Key เพื่อขอราคาประเมิน
