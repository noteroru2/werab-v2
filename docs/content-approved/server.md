# รับซื้อ Server มือสอง เช็กสเปก อุปกรณ์ และสภาพก่อนขาย

มี Server มือสองจากบริษัท สำนักงาน หรือระบบเดิมที่เลิกใช้งาน แต่ยังไม่แน่ใจว่าควรแจ้งข้อมูลอะไรเพื่อประเมินราคา?

Server ต้องดูรายละเอียดมากกว่าชื่อรุ่นเพียงอย่างเดียว เพราะเครื่องรุ่นเดียวกันอาจติดตั้ง **CPU, RAM, Storage, RAID Controller, Network Card, Power Supply และอุปกรณ์ภายใน** ต่างกันมาก

ก่อนขายควรเริ่มจากส่ง:

**Brand + Model + Service Tag/Serial ที่ไม่ใช่ข้อมูลลับ + CPU + RAM + Storage + Controller + รูปเครื่อง + สภาพ**

## Server แบบไหนส่งมาประเมินได้

สามารถส่งข้อมูล Server มือสองหลายประเภทมาสอบถามได้ เช่น

- Rack Server
- Tower Server
- Enterprise Server
- Server สำหรับสำนักงาน
- File Server
- Application Server
- Virtualization Server
- Server ที่เลิกใช้งานจากระบบเดิม
- Server ที่ถอด Storage ออกแล้ว
- Server ที่เพิ่ม RAM หรือ Storage ภายหลัง
- Server ที่มีหลาย CPU
- Server ที่มีหลาย Power Supply
- Server ที่มีอุปกรณ์เสริมเฉพาะ
- Server หลายเครื่องจากบริษัทหรือองค์กร
- Server ที่มีอาการบางประเภท
- Server ที่ยังไม่ได้ทดสอบ

การประเมินต้องดูรุ่น Configuration และสภาพจริงของแต่ละเครื่อง

---

## ก่อนขายต้องรู้ Brand และ Model ให้ชัด

Server แต่ละตระกูลมีหลาย Generation และหลาย Configuration

ข้อมูลที่ควรหา เช่น

- Brand
- Model
- Generation
- Form Factor
- Service Tag หรือ Serial Number หากใช้ตรวจรุ่นได้และไม่เกี่ยวข้องกับข้อมูลบัญชี
- รุ่น Chassis
- จำนวน Bay
- Configuration ปัจจุบัน

ตัวอย่างแบรนด์ที่พบในตลาด เช่น

- Dell
- HPE
- Lenovo
- Cisco
- Supermicro
- Fujitsu
- IBM รุ่นเก่า
- และแบรนด์อื่น

ไม่ควรประเมินจากคำว่า “Server Dell” หรือ “Server HP” เพียงอย่างเดียว

---

## Rack Server กับ Tower Server ควรแยกให้ชัด

Server อาจมีรูปแบบตัวเครื่องต่างกัน

### Rack Server

มักติดตั้งใน Rack และควรดูข้อมูลเพิ่ม เช่น

- ขนาด 1U, 2U หรือรูปแบบอื่น
- Rail
- Front Bezel
- จำนวน Drive Bay
- Power Supply
- Network Interface

### Tower Server

รูปทรงคล้ายเครื่อง Tower แต่ Hardware และระบบภายในออกแบบสำหรับงาน Server

ควรแจ้ง Model ให้ชัดเพื่อไม่ให้สับสนกับ Desktop หรือ Workstation

---

## Server ต่างจากคอมพิวเตอร์มือสองทั่วไปอย่างไร

หน้า `/รับซื้อคอม/` ใช้กับ Desktop, Gaming PC และคอมประกอบทั่วไปเป็นหลัก

ส่วนหน้า `/รับซื้อ-server/` ใช้กับระบบ Server ที่มีลักษณะเฉพาะ เช่น

- Xeon หรือ CPU สำหรับ Server
- ECC Memory
- RAID Controller
- Hot-Swap Drive Bay
- Redundant Power Supply
- Management Interface
- Enterprise Network Card
- Rack Chassis
- Hardware Configuration หลายรูปแบบ

จึงควรแยก Intent และข้อมูลการประเมินออกจากคอมพิวเตอร์ทั่วไป

---

## CPU เป็นข้อมูลสำคัญของ Server

ควรแจ้งรุ่น CPU เต็มถ้าทราบ เช่น

- Intel Xeon E Series
- Intel Xeon Silver
- Intel Xeon Gold
- Intel Xeon รุ่นอื่น
- AMD EPYC
- CPU สำหรับ Server รุ่นอื่น

และควรแจ้ง:

- จำนวน CPU ที่ติดตั้ง
- รุ่นของแต่ละ CPU
- จำนวน Core ถ้าทราบ
- เครื่องรองรับหลาย Socket หรือไม่
- CPU ถูกถอดออกบางตัวหรือไม่

Server Chassis เดียวกันอาจมี Configuration CPU ต่างกันมาก จึงไม่ควรใช้ราคา Chassis อย่างเดียวเป็นฐาน

---

## Server มี CPU สองตัวต้องแจ้งทั้งสองตัวไหม

ควรแจ้ง

ตัวอย่าง:

**CPU: Xeon Silver รุ่น... × 2**

หากเครื่องรองรับ Dual CPU แต่ติดตั้งเพียง 1 ตัว ควรแจ้งว่า:

**ติดตั้ง CPU 1 ตัว**

ไม่ควรสรุปว่ามี 2 CPU เพียงเพราะ Mainboard มี 2 Socket

---

## RAM Server ต้องดูอะไร

RAM เป็นอีกส่วนที่มีผลต่อ Configuration

ควรแจ้ง:

- ความจุรวม
- จำนวนแถว
- ความจุต่อแถว
- DDR Generation
- ECC หรือไม่ถ้าทราบ
- Registered / RDIMM / LRDIMM ถ้าทราบ
- ความเร็ว
- มี Slot ว่างหรือไม่

ตัวอย่าง:

**RAM 128GB ECC — 32GB × 4**

หากไม่ทราบรายละเอียดทั้งหมด ให้แจ้งความจุรวมและถ่ายรูป Label ของ RAM เท่าที่ทำได้อย่างปลอดภัย

---

## ECC RAM มีผลต่อการประเมินไหม

มีผลใน Server หลายประเภท เพราะประเภท RAM ต้องเข้ากันกับ Platform และ Configuration ของเครื่อง

แต่ไม่ควรสรุปจากรูปลักษณ์เพียงอย่างเดียว

หากไม่แน่ใจ ให้ส่ง:

- Model Server
- รูป RAM
- Part Number
- ข้อมูลจาก BIOS หรือระบบที่อ่านได้

เพื่อใช้ประกอบการตรวจรุ่น

---

## Storage ต้องแจ้งทั้งจำนวนและประเภท

Server อาจติดตั้ง Storage หลายลูก

ควรแจ้ง:

- SSD หรือ HDD
- SAS / SATA / NVMe ถ้าทราบ
- ความจุต่อ Drive
- จำนวน Drive
- มี Tray/Caddy หรือไม่
- Drive ถูกถอดออกบางส่วนหรือไม่
- สถานะการทำงานถ้าทราบ

ตัวอย่าง:

**SAS 1.2TB × 4 พร้อม Caddy**

หรือ

**ขายเครื่องไม่รวม Drive**

ต้องประเมินจากอุปกรณ์ที่ขายจริง

---

## Server ไม่มี HDD หรือ SSD ยังขายได้ไหม

สามารถส่งมาประเมินได้

Server ที่ถอด Storage ออกแล้วควรแจ้งชัดว่า:

**ไม่รวม Storage**

และควรแจ้งว่า Drive Tray หรือ Caddy ยังอยู่หรือถูกถอดไปด้วย

Chassis, CPU, RAM, Controller, PSU และอุปกรณ์อื่นยังสามารถเป็นส่วนหนึ่งของการประเมินได้

---

## ข้อมูลใน Server ต้องจัดการก่อนขายอย่างไร

Server มักมีข้อมูลบริษัท ระบบงาน ฐานข้อมูล หรือข้อมูลภายในองค์กรอยู่ใน Storage

ก่อนขายควรตัดสินใจให้ชัดว่า:

- จะเก็บ Drive ไว้
- จะ Backup ข้อมูล
- จะล้างข้อมูลตามนโยบายองค์กร
- หรือจะขาย Storage รวมด้วย

หากยังไม่พร้อมจัดการข้อมูล สามารถขอประเมินตัว Server โดย:

**ไม่รวม Storage**

ได้

ไม่ควรส่ง:

- Password
- Root Password
- Domain Credential
- Administrator Password
- Encryption Key
- Recovery Key
- API Key
- ข้อมูลลูกค้า
- ข้อมูลลับของบริษัท

เพื่อขอราคาประเมินเบื้องต้น

---

## RAID Controller มีผลต่อราคาไหม

มีผลใน Server หลายรุ่น

ควรแจ้ง:

- รุ่น Controller
- มี Cache หรือไม่ถ้าทราบ
- มี Battery/Cache Protection Module หรือไม่
- จำนวน Drive ที่เชื่อมต่อ
- Controller เดิมยังอยู่หรือถูกถอดออก
- มีอาการ Error หรือไม่

ไม่ควรลบ RAID Configuration หรือ Initialize Drive เพียงเพื่อถามราคา หากยังมีข้อมูลที่ต้องเก็บรักษา

---

## RAID ไม่ใช่การสำรองข้อมูลเสมอไป

หาก Server ยังมีข้อมูลสำคัญ ไม่ควรถือว่ามี RAID แล้วข้อมูลจะปลอดภัยเสมอ

ก่อนเปลี่ยน Configuration, ถอด Drive หรือ Initialize Array ควรให้ผู้รับผิดชอบระบบขององค์กรตรวจสอบข้อมูลก่อน

การเช็กราคาตัวเครื่องไม่จำเป็นต้องเปลี่ยน RAID Configuration

---

## Network Card และ Interface ควรแจ้งไหม

สำหรับ Server ที่มี Network Configuration พิเศษควรแจ้ง เช่น

- 1GbE
- 10GbE
- 25GbE หรือประเภทอื่น
- SFP/SFP+ Adapter
- Fibre Channel Card
- Add-on NIC
- Management Port

หากมี Card เสริม ควรถ่ายรูปหรือแจ้ง Part Number

อุปกรณ์เหล่านี้อาจมีมูลค่าแยกจาก Configuration พื้นฐานของเครื่อง

---

## Power Supply ต้องดูจำนวนและกำลังไฟ

Server หลายรุ่นใช้ Redundant PSU

ควรแจ้ง:

- จำนวน PSU
- Watt
- รุ่นหรือ Part Number
- มีครบตาม Bay หรือไม่
- มีอาการหรือไฟ Error หรือไม่

ตัวอย่าง:

**PSU 750W × 2**

หากเครื่องรองรับ 2 PSU แต่มีเพียงตัวเดียว ต้องแจ้งตามสภาพจริง

---

## Rail และ Front Bezel มีผลไหม

มีผลต่อความครบของ Rack Server

ควรแจ้งว่า:

- มี Rail หรือไม่
- Rail ครบคู่หรือไม่
- มี Front Bezel หรือไม่
- มีกุญแจ Bezel หรือไม่ถ้ามี
- มี Cable Management Arm หรือไม่
- มี Rack Accessories อื่นหรือไม่

ไม่มีก็ยังสามารถส่งมาประเมินได้ แต่ควรแจ้งสิ่งที่มีจริง

---

## Management Interface ต้องแจ้งข้อมูลอะไร

Server บางรุ่นมีระบบจัดการระยะไกล เช่น Management Interface เฉพาะของผู้ผลิต

ควรแจ้งเพียง:

- ระบบ Management มีหรือไม่
- เข้าใช้งานได้หรือไม่ถ้าทดสอบอย่างถูกต้อง
- มี License เพิ่มเติมหรือไม่ถ้าตรวจสอบได้

ไม่ควรส่ง Username, Password หรือ Credential ของระบบ Management เพื่อขอราคา

ก่อนส่งมอบจริง เจ้าของควรจัดการบัญชีและการตั้งค่าที่เกี่ยวข้องตามนโยบายของตนเอง

---

## BIOS หรือ Hardware Inventory ช่วยประเมินได้ไหม

หาก Server ยังเปิดได้ ข้อมูลจาก BIOS หรือ Hardware Inventory สามารถช่วยระบุ Configuration ได้ เช่น

- CPU
- RAM
- Storage
- Controller
- NIC
- Firmware Information
- Hardware Status

สามารถถ่ายรูปหน้าจอส่วน Hardware Summary ที่ไม่มีข้อมูลลับประกอบการประเมินได้

ไม่จำเป็นต้องส่งภาพหน้าจอที่มีข้อมูลเครือข่ายหรือ Credential ภายในองค์กร

---

## Server เปิดไม่ติดยังประเมินได้ไหม

บางกรณีสามารถส่งข้อมูลมาประเมินตามสภาพได้

ควรแจ้ง:

- Brand
- Model
- CPU
- RAM
- Storage ที่ยังอยู่
- Controller
- PSU
- อาการ
- ไฟสถานะ
- Error Code ถ้ามี
- เคยซ่อมหรือไม่

Server ที่ไม่สามารถทดสอบได้มีความไม่แน่นอนสูงกว่าเครื่องที่ตรวจ Configuration และ Hardware Status ได้ครบ

---

## มีไฟ Error ควรแจ้งอย่างไร

หากมี:

- Warning LED
- PSU Error
- Fan Error
- Memory Error
- Storage Error
- Controller Error
- Hardware Alert

ควรถ่ายรูปและแจ้งข้อความหรือ Code ที่เห็น

ไม่ควรลบ Log หรือ Reset Configuration เพียงเพื่อให้สถานะ Error หายก่อนประเมิน

ข้อมูล Error ช่วยอธิบายสภาพจริงของเครื่องได้

---

## Server มีเสียงพัดลมดังผิดปกติยังประเมินได้ไหม

สามารถส่งข้อมูลมาประเมินได้

ควรแจ้งว่า:

- พัดลมดังตั้งแต่เปิด
- ดังหลัง Boot
- มี Fan Error
- มีพัดลมบางตัวไม่หมุน
- เครื่องเคยเปลี่ยน Fan
- มี Hardware Error อื่นร่วมด้วยหรือไม่

Server บางรุ่นมีระดับเสียงสูงตามลักษณะการใช้งานอยู่แล้ว จึงไม่ควรสรุปว่าเสียจากความดังเพียงอย่างเดียว

---

## Server เคยซ่อมหรือเปลี่ยนอะไหล่ต้องแจ้งไหม

ควรแจ้งหากทราบ

เช่นเคย:

- เปลี่ยน Mainboard
- เปลี่ยน PSU
- เปลี่ยน Fan
- เปลี่ยน Backplane
- เปลี่ยน RAID Controller
- เปลี่ยน Drive
- เพิ่ม RAM
- เปลี่ยน CPU
- ซ่อมระบบ Power
- ซ่อมอุปกรณ์ภายใน

ประวัติซ่อมไม่ได้หมายความว่าจะขายไม่ได้ แต่ช่วยให้ประเมิน Configuration และความเสี่ยงได้ตรงขึ้น

---

## Server เก่ามากยังส่งมาประเมินได้ไหม

สามารถส่งข้อมูลมาดูก่อนได้

แต่ Server รุ่นเก่าอาจมีปัจจัย เช่น

- ประสิทธิภาพต่อพลังงานต่ำกว่า Platform ใหม่
- ใช้ RAM หรือ Storage Generation เก่า
- Firmware และ Software Support จำกัด
- อุปกรณ์ทดแทนหาได้ยากขึ้น
- ความต้องการในตลาดลดลง
- ค่าไฟและต้นทุนการใช้งานสูงเมื่อเทียบกับประสิทธิภาพ

ดังนั้นราคาตอนซื้อใหม่ไม่ใช่ฐานที่เหมาะสมสำหรับประเมินราคาปัจจุบัน

---

## Server ที่ถอด RAM หรือ CPU บางส่วนออกแล้วขายได้ไหม

สามารถส่งมาประเมินได้

ต้องแจ้ง Configuration ปัจจุบัน ไม่ใช่ Configuration เดิม

ตัวอย่าง:

เดิมมี:

**CPU × 2 / RAM 256GB**

แต่ปัจจุบันเหลือ:

**CPU × 1 / RAM 64GB**

ควรใช้ข้อมูลปัจจุบันในการประเมิน

ไม่ควรระบุสเปกเดิมโดยไม่บอกว่ามีการถอดอุปกรณ์ออก

---

## Server หลายเครื่องควรส่งข้อมูลอย่างไร

หากมีหลายเครื่องควรจัดรายการ

| รุ่น | CPU | RAM | Storage | จำนวน | สภาพ |
|---|---|---|---|---|---|
| รุ่น... | Xeon... × 2 | 128GB | ไม่รวม Drive | 4 | เปิดติด |
| รุ่น... | Xeon... | 64GB | SAS × 4 | 3 | มี Error |
| รุ่น... | ไม่ทราบ | ไม่ทราบ | ไม่มี | 2 | ยังไม่ได้ทดสอบ |

หาก Configuration ต่างกันมาก ควรแยกเป็นแต่ละกลุ่ม

ไม่ควรรวมหลาย Configuration ไว้ในราคาหรือสเปกเดียว

9. PSU

## ควรขาย Server ทั้งเครื่องหรือแยกอะไหล่

ขึ้นอยู่กับ Configuration และความสะดวก

### ขายทั้งเครื่อง

เหมาะเมื่อ:

- Configuration ยังครบ
- ต้องการจัดการ Server ทั้งชุด
- ไม่ต้องการถอด Hardware
- มีหลายเครื่อง
- ต้องการลดขั้นตอนในการแยกชิ้น

### แยกชิ้น

บางกรณีอาจพิจารณาอุปกรณ์ที่มีตลาดแยก เช่น

- CPU
- RAM
- SSD
- HDD
- RAID Controller
- NIC
- PSU
- Rail

แต่ควรประเมินก่อนว่าของที่เหลือหลังถอดอุปกรณ์สำคัญยังมีมูลค่าและจัดการได้อย่างไร

## Server เสียหนักควรดูเป็นซากคอมพิวเตอร์หรือ Server

หากยังสามารถระบุได้ว่าเป็น Enterprise Server และ Configuration หลักยังอยู่ การเริ่มประเมินจากหน้า Server ช่วยให้เห็นอุปกรณ์เฉพาะของ Server ได้ครบกว่า

แต่หากเหลือเป็นชิ้นส่วนทั่วไปจำนวนมาก ไม่มี Configuration เดิม หรือสภาพเป็นชุดอะไหล่เสีย อาจต้องพิจารณามูลค่าคงเหลือในลักษณะเดียวกับซากคอมพิวเตอร์

หลักสำคัญคือประเมินจากของที่เหลือและสถานะจริง ไม่ใช่ชื่อเดิมของระบบเพียงอย่างเดียว

## ปัจจัยหลักที่ใช้ประเมิน Server มือสอง

### Brand และ Model

ใช้ระบุ Platform และ Generation

### Generation

Server ชื่อ Series เดียวกันอาจมีหลาย Generation

### CPU

ดูรุ่น จำนวน และ Platform

### RAM

ดูประเภท ความจุ จำนวนและ Configuration

### Storage

ดูชนิด ความจุ จำนวน และ Tray/Caddy

### RAID Controller

ดูรุ่นและอุปกรณ์ที่ติดตั้ง

### Network

NIC หรือ Adapter พิเศษอาจมีมูลค่าเพิ่มเติม

### Power Supply

ดูจำนวน Watt และสถานะ

### Rail และ Accessories

มีผลต่อความครบสำหรับ Rack Server

### Hardware Status

เครื่องที่ตรวจสอบได้กับเครื่องที่ยังไม่ได้ทดสอบมีความไม่แน่นอนต่างกัน

### ประวัติซ่อม

ช่วยประเมินความเสี่ยงของ Hardware

### Storage และข้อมูล

ต้องแยกความเป็นเจ้าของข้อมูลออกจากมูลค่าของ Hardware

### จำนวนเครื่อง

ล็อตหลายเครื่องควรแยกตาม Model และ Configuration

### ตลาดของ Platform

ความต้องการของ Server แต่ละ Generation เปลี่ยนแปลงตามเวลา

## ขั้นตอนเช็กราคา Server ก่อนขาย

### 1. ส่ง Brand และ Model

แจ้งรุ่นเต็มของเครื่อง

### 2. ส่งรูป

ถ่าย:

- ด้านหน้า
- ด้านหลัง
- ด้านบนหรือด้านข้างตามรูปแบบเครื่อง
- ภายในถ้าเปิดได้อย่างปลอดภัย
- ป้าย Model
- จุดตำหนิ
- อุปกรณ์ที่มี

### 3. แจ้ง CPU

ระบุรุ่นและจำนวน CPU

### 4. แจ้ง RAM

ระบุความจุรวมและจำนวนแถวเท่าที่ทราบ

### 5. แจ้ง Storage

ระบุประเภท ความจุ จำนวน และรวมขายหรือไม่

### 6. แจ้ง Controller และ Network

ระบุ RAID Controller และ Network Card ถ้าทราบ

### 7. แจ้ง PSU และอุปกรณ์

เช่น PSU, Rail, Bezel และอุปกรณ์เสริม

### 8. แจ้งสภาพและอาการ

เปิดติดหรือไม่ มี Error หรือเคยซ่อมหรือไม่

### 9. ประเมินเบื้องต้น

พิจารณา Platform, Configuration, สภาพ และความครบของอุปกรณ์ร่วมกัน

### 10. ตรวจสินค้าและซื้อขาย

ตรวจ Model, Configuration, Hardware และสิ่งที่รวมขายให้ตรงกับข้อมูลที่ใช้ประเมินก่อนดำเนินการซื้อขาย

## คำถามที่พบบ่อยเกี่ยวกับการรับซื้อ Server

### Server มือสองต้องส่งข้อมูลอะไรเพื่อเช็กราคา?

ควรส่ง Brand, Model, CPU, RAM, Storage, RAID Controller, Network Card, PSU, จำนวน และรูปเครื่อง หากมีหลาย Configuration ควรแยกข้อมูลแต่ละกลุ่ม

### Server ไม่มี HDD หรือ SSD ยังขายได้ไหม?

สามารถส่งมาประเมินได้ ควรแจ้งว่าไม่รวม Storage และระบุว่า Drive Tray หรือ Caddy ยังอยู่หรือไม่ ราคาจะพิจารณาจาก Hardware ที่รวมขายจริง

### Server เปิดไม่ติดหรือมี Hardware Error ยังขายได้ไหม?

บางกรณีสามารถส่งมาประเมินตามสภาพได้ ควรแจ้ง Model, Configuration, อาการ, Error Code หรือไฟสถานะ และประวัติซ่อมเท่าที่ทราบ

### Server มีข้อมูลบริษัทอยู่ใน HDD ต้องทำอย่างไร?

ควรให้เจ้าของข้อมูลหรือผู้รับผิดชอบระบบกำหนดวิธี Backup ล้างข้อมูล หรือเก็บ Drive ไว้ก่อนขาย หากยังไม่พร้อมสามารถขอประเมิน Server โดยไม่รวม Storage ได้ และไม่ควรส่ง Password หรือข้อมูลลับเพื่อขอราคา

### มี Server หลายเครื่องจากบริษัทประเมินอย่างไร?

ควรจัดรายการตาม Model, CPU, RAM, Storage, Controller, จำนวนและสภาพ หาก Configuration ต่างกันควรแยกแต่ละกลุ่ม เพื่อให้ประเมินจากอุปกรณ์ที่มีอยู่จริงได้ชัดเจนขึ้น
